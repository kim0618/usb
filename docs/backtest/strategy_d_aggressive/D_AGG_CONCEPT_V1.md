## 1. D V2-A와의 관계

```text
D V1    HISTORICAL_ANALOG_V1          CLOSED / FAIL
D V2-A  MARKET_STRUCTURE_ANALOG_V2    D0~D3 PASS, D4 = SCREENING_FAIL (S6, S7)   <- 변경 없음
D-AGG   MARKET_STRUCTURE_ANALOG_TAIL_V1  이번 선언
```

**D-AGG는 V2-A를 되살리는 연구가 아니다.** V2-A의 공식 판정은 `SCREENING_FAIL`로 남고, 이 연구의 어떤
결과도 그것을 바꾸지 못한다. 이 연구는 V2-A가 동결한 신호 `A(q)`를 **입력으로 빌려 쓰고**, 전혀 다른
질문을 던진다.

| | D V2-A | D-AGG |
| --- | --- | --- |
| 목적 | 안정적 방향성 알파 | 큰 상방 움직임 포착 + 비대칭 payoff |
| 응답 | `excess_return_5`의 순위 | `MFE_5`, `MAE_5`의 꼬리 사건 |
| 표본 | query 전체의 순위 상관 | `A(q)` 상위 10%만 (선택적) |
| 비교 | B0 합성지표 대비 IC 차이 | 같은 날 적격 유니버스 대비 꼬리 발생률 |
| primary | `mean delta IC` | 상방 꼬리 lift `TL` |
| 허용 | - | 낮은 승률, 낮은 IC, 낮은 빈도, 일부 구간 약세 |
| 불허 | - | 변동성만 큰 종목 탐지, 소수 날짜·종목 집중 |

V2-A는 "A가 B0보다 순위를 잘 매기는가"를 물었고 비교 분산 때문에 답을 못 냈다. D-AGG는 "A 상위 10%에
+10% 움직임이 더 자주, 그리고 하방보다 더 많이 몰리는가"를 묻는다. 비교 대상이 합성지표가 아니라
유니버스 자체라서 V2-A를 무너뜨린 paired 분산(`sd(IC_B0)`가 `sd(IC_A)`의 2.06배) 문제가 구조적으로
없다.

## 2. 신호: 새로 만들지 않는다

`A(q) = 수락된 top-50 구조 아날로그 이웃의 excess_return_5 중앙값`을 V2-A D3 산출물에서 그대로 읽는다.
10좌표, 순위 스케일링, 등가중 Euclidean, K=50, h=5, embargo, cap, 표본 규칙 전부 V2-A 값이다.

이 선택의 이유는 자유도다. 2년 창은 이미 네 번째로 읽히는 **개발 데이터**다(D V1, C-4, D V2-A, D-AGG).
신호를 새로 짜면 그 자체가 이 창에 대한 추가 적합이 된다. 재사용하면 이번 연구가 새로 고른 것은
평가 방식뿐이고, 그 평가 방식은 이 문서와 규칙 JSON에 결과 전에 고정된다.

부모 바인딩은 `signal_rows` 전체 digest가 아니라 **A 관련 열만의 digest**로 한다. V2-A D4 §11이 측정한
대로 `b0` 열은 머신마다 최대 2 ULP 갈리지만(BLAS 합산 순서), `A(q)`는 행렬곱을 타지 않는다. 전체 digest로
묶으면 다른 머신에서 D-AGG를 재현할 수 없다.

## 3. 사전 노출 공개 (결과를 전혀 안 본 상태가 아니다)

요청문은 "결과를 보고 threshold를 고르지 말 것"을 요구한다. 그 요구를 지키려면 **이미 본 것**부터 적어야
한다. 선언 시점에 다음이 보였다.

| 출처 | 내용 |
| --- | --- |
| V2-A D4 S-12 | `A(q)` 5분위별 **평균** MFE_5: Q1 0.0683 / 0.0475 / 0.0454 / 0.0470 / Q5 0.0591 |
| V2-A D4 S-12 | 같은 분위별 평균 MAE_5: -0.0605 / -0.0435 / -0.0405 / -0.0421 / -0.0524 |
| V2-A D4 | `mean IC(A)` +0.0172, S8 Q5-Q1 excess +0.0021, 라벨 무효 138/66,300 |
| Strategy C GATE-C2 | 다른 선택 신호에서 MFE lift 1.36인데 10일 종가 초과 0, 즉 **lift가 변동성**이었다 |
| Strategy C V2B | VOLATILITY 분류(로그 대칭, TR 군집) |

본 적 **없는** 것: 어떤 집단의 꼬리 발생률(`P(MFE >= x)`), 상위 10% 통계, +5/+10/+15% 문턱별 비교,
유니버스 기저율. 따라서 문턱 후보들을 결과 위에서 비교해 고르는 일은 일어나지 않았다.

그러나 이미 본 것이 말하는 바는 분명하다. **MFE와 MAE가 둘 다 U자형이다.** Q5는 Q2~Q4보다 MFE가 크지만
MAE도 크고, Q5의 평균 `MFE/|MAE|` 비율 1.128은 분위 평균 1.118과 거의 같다. Q1은 더 극단적이다. 이것은
"A 극단값 = 변동성 큰 종목"이라는 패턴이며, Strategy C가 이미 한 번 걸린 함정과 같다.

이 사전 정보가 설계에 준 영향은 **한 방향뿐**이다: 변동성 선택을 탈락시키는 조건(H5, H6, T4)을 필수로
넣었다. 문턱을 낮추거나 통과하기 쉽게 만든 곳은 없다. 그리고 다음 두 가지는 명시적으로 금지한다.

```text
Q1의 평균 MFE가 가장 크다는 이유로 하위 10% 또는 양쪽 꼬리로 setup을 바꾸는 것
D-AGG-1에서 기저율을 본 뒤 문턱·분위·horizon·비교대상을 다시 고르는 것
```

**사전 기대(pre-mortem)**: 이미 본 분위 평균만으로는 상위 10%의 TL이 1보다 약간 클 가능성이 높지만,
DL도 비슷하게 올라 NTL이 1 근처일 가능성이 높다. 즉 이 연구의 가장 가능성 높은 결말은 H5/H6/T4에서의
FAIL이다. 그래도 선언하는 이유는 (1) 평균은 꼬리 확률이 아니고 상위 10%는 본 적이 없으며, (2) 변동성과
비대칭을 분리하는 검정은 이 신호에 대해 한 번도 수행되지 않았고, (3) 비용이 작기 때문이다(§7).

## 4. 설계 선택과 근거

### 4.1 Primary setup = 날짜별 A(q) 상위 10%

- query 300개 중 상위 30개/날짜, 221일에 약 6,630건. Top 5%(약 3,300)보다 블록당 표본이 두 배다.
- 분위는 **날짜 안에서** 자른다. 풀에서 자르면 후기 레짐이 초기 날짜의 선택을 결정한다(V1 분위 코드와
  같은 원칙, V2-A D4 S8의 모호성을 선언에서 제거).
- **라벨 유효성을 보기 전에** signal OK query에서 선택하고, 무효 라벨은 나중에 버리며 계수한다. 5일 뒤
  봉이 있는지가 선택에 끼어들면 미래 정보다.

### 4.2 Primary tail = `MFE_5 >= +10%`, downside = `MAE_5 <= -10%`

- +5%는 5세션 전형 excursion 규모(약 5%)의 한가운데라 꼬리가 아니다. +15%는 30개 setup에서 날짜당 사건이
  1개 안팎이라 블록 추정이 흔들린다. +10%는 전형 규모의 약 2배로 꼬리이면서 표본이 남는다.
- "전형 규모 약 5%"는 S-12의 무조건 평균 크기와 `sqrt(5) x 일간 2.5~3%`에서 나온 규모 정보이고, A에 조건부인
  정보가 아니다. 이 규모 정보를 썼다는 사실을 숨기지 않는다.
- **하방 문턱은 상방의 거울상**이다. 대칭이어야 "변동성만 큰 선택"이 `TL ~ DL`로 드러난다. 요청문 예시의
  -5%를 쓰면 상하방 사건의 희귀도가 달라 비교가 성립하지 않는다.

### 4.3 Primary metric = 날짜 층화 tail lift `TL`

```text
TL = sum_t p_up_S(t) / sum_t p_up_U(t)
```

- 해석이 쉽다: "같은 날 아무 적격 종목을 고르는 것보다 +10% 도달이 몇 배 잦은가".
- 비율을 택한 결정적 이유: **문턱이 기저율에 의존하지 않는다.** 이번 D0는 기저율을 보지 않았다. 확률 차이
  (TEP)를 primary로 하면 "몇 %p면 충분한가"를 정하려고 기저율이 필요했을 것이다. TEP는 기술통계로 둔다.
- 날짜 합으로 층화한다. 시장 전체가 급등한 날은 분자와 분모가 같이 오르므로 A의 능력으로 계산되지 않는다
  (Mantel-Haenszel형 층화 위험비, 날짜 등가중).

### 4.4 변동성 판별 = NTL과 AG

설계 단계에서 합성 시뮬레이션을 1회 돌렸다(리포 밖 scratchpad, 코드 추가 0). 드리프트 0, 일간 변동성
로그정규(중앙값 2.5%), 선택 점수가 변동성과만 상관하는 세계:

| 변동성 기울기 | TL | DL | NTL = TL/DL | AG |
| --- | --- | --- | --- | --- |
| 0.3 | 1.547 | 1.603 | 0.965 | 0.991 |
| 0.6 | 2.234 | 2.359 | 0.947 | 0.987 |
| 1.0 | 3.310 | 3.687 | 0.898 | 0.985 |

**TL만 보면 순수 변동성 선택이 1.25 문턱을 쉽게 넘는다.** 반면 NTL과 AG는 1 아래로 떨어진다(대칭 문턱에서
%하방 -10%가 로그로 더 멀어 희귀하므로, 변동성이 오르면 하방 lift가 더 크게 오른다). 그래서

- H5 `NTL >= 1.00`, H6 `AG >= 1.00`을 **하드 조건**으로 두고,
- T4 `NTL >= 1.10`을 PASS 수준으로 둔다.

AG는 날짜별 중앙값을 먼저 합산하고 나서 비율을 만든다. 날짜별 비율은 강한 상승주간에 `|median MAE|`가 0에
가까워질 수 있어 만들지 않는다. `MAE_5 <= 0`, `MFE_5 >= 0`은 봉의 정의상 항상 성립한다(`L <= O <= H`).

이 시뮬레이션은 **데이터가 아니다.** 조건의 방향을 확인하는 용도이며 문턱 수치는 시뮬레이션에 맞춰
튜닝하지 않았다.

### 4.5 Comparator = 같은 날 적격 유니버스

질문이 "A가 큰 움직임 후보를 농축하는가"이므로 비교 대상은 "그날 아무거나 고르기"다. 유니버스는 V2-A가
`excess_return_5` 중앙값을 만들 때 쓰는 것과 같은 모집단(날짜당 약 2,600종목)이다. setup이 유니버스에
포함되는 약 1%의 중복은 lift를 1 쪽으로 당기는 보수적 편향이라 보정하지 않는다.

B0 상위 10%, rv_20 상위 10%, rv_20 분위 매칭 유니버스는 전부 **secondary**다. 특히 rv_20 상위 10%(X-6)와
변동성 매칭(X-7)은 "A가 변동성 이상의 무엇을 하는가"에 대한 가장 직접적인 기술통계이므로 반드시 싣는다.
판정은 바꾸지 않는다: 공격형 목표에서는 변동성을 통해 오는 비대칭이라도 비대칭이면 된다. 판정이 거르는
것은 **비대칭 없는** 변동성이다.

## 6. 이 연구가 말할 수 있는 것과 없는 것

PASS가 뜻하는 것: 이 2년 창에서 A 상위 10%가 같은 날 유니버스보다 +10% 도달이 1.25배 이상 잦고, 하방
꼬리보다 상방 꼬리가 더 많이 늘며, 소수 날짜·종목이 이를 설명하지 않는다. **그래서 매매 규칙과 백테스트
설계를 선언할 가치가 있다.**

PASS가 뜻하지 않는 것:

- 수익이 난다는 것. MFE는 창이 한 번 닿은 최고가이지 규칙이 청산할 수 있는 가격이 아니다. 같은 날 고가와
  저가 중 어느 것이 먼저인지 일봉은 모른다. 포착률은 trading rule 단계의 몫이다.
- 알파라는 것, 다른 레짐에서 성립한다는 것(이 창은 사실상 단일 상승 레짐이다, V2-A §10).
- 장기 데이터 구매 근거. US-B 순서는 PASS -> 규칙/백테스터 -> historical backtest -> Virtual Trading -> forward
  확인 -> 그 뒤 Long Data 검토다.

FAIL이 닫는 것: 이 신호(A), 이 setup(상위 10%), 이 문턱(+/-10%), 이 창에서의 꼬리 포착 가설. Historical
Analog 전체나 V2-A 해석(`WATCHLIST`)을 닫지 않는다.

## 7. 비용

신호·이웃·라벨이 V2-A 산출물로 이미 있다. 새로 필요한 것은 유니버스 전체의 `MFE_5`/`MAE_5` 행렬
(`compute_extremes`가 이미 `(T, N)`으로 만든다), 사건 지표, 날짜 층화 비율, 부트스트랩, 게이트다. D-V2A-4가
83.5초에 끝났으므로 D-AGG 채점도 분 단위로 추정한다(측정값 아님). 다른 머신에서는 V2-A D1~D3 재생성에
약 10분이 더 든다.

## 0. 이 연구가 답하려는 것

```text
Market Structure Analog 아이디어가, 약 2년의 frozen 저장소 위에서
"장기 Historical Data를 구매하고 더 깊게 검증할 만큼의 정보가치"를 보이는가
```

PASS는 **구매·장기연구 가치 있음**을 뜻한다. PASS는 Backtester 승인도, 실거래 승인도,
알파 존재 증명도 아니다. 이 제한은 §7에 명시적으로 고정한다.

## 1. V1과 무엇이 다른가

| 축 | V1 HISTORICAL_ANALOG_V1 | V2-A MARKET_STRUCTURE_ANALOG_V2 |
| --- | --- | --- |
| 질문 | 가격 경로의 모양이 비슷한가 | 시장 구조 상태가 비슷한가 |
| 신호 입력 | 종가 경로 `P(D-W..D)` (표현 A/B) | 구조 좌표 10개 (경로 미사용) |
| 유사도 좌표계 | raw price path | market structure feature vector |
| primary 비교 대상 | 랜덤 아날로그(N1) 대비 우위 | **같은 좌표의 등가중 합성지표(B0) 대비 우위** |
| primary 검정 수 | 14 (7조합 x 2표현), Bonferroni | **1** |
| 판정 공간 | PASS / INCONCLUSIVE / FAIL (알파 게이트) | PASS / BORDERLINE / FAIL (**스크리닝 게이트**) |
| 판정의 의미 | 알파 사전검증 | 장기 데이터 구매 판단 |

V1 경로 인코더(`encoder.py`)는 V2-A의 신호 입력에서 **완전히 제거**한다(§4). 따라서 V2-A는
"V1에 좌표를 더한 것"이 아니라 좌표계를 교체한 별도 연구다.

### 1.1 V1 결과를 근거로 쓰지 않은 것 (금지 목록 대조)

| 금지 항목 | V2-A에서의 처리 |
| --- | --- |

| representation B 채택 | A/B 둘 다 미사용 |

SE 팽창 1.25배(post-mortem §3.2). 이 두 값은 효과크기가 아니라 **검정력 계산의 입력**이며,
요청문 §29가 요구한 MDE 산출에 쓰였다. 효과크기(IC +0.0177 등)는 어떤 threshold에도 쓰지 않았다.

## 2. Primary Research Question

```text
Market Structure Analog 신호가, 동일한 좌표를 단순 합성한 baseline(B0)보다
미래 excess return 예측에서 추가 정보를 제공하는가
```

"아날로그 IC > 0"만 보지 않는 이유는 아날로그 기계의 주장이 **좌표가 좋다**가 아니라
**과거 유사 사례의 실현 분포가 선형 결합보다 많은 것을 담는다**이기 때문이다. 비선형성,
좌표간 상호작용, 조건부 분포가 그 주장의 내용이다. 같은 좌표의 등가중 합성지표를 이기지
못하면 이웃 탐색 기계 전체가 불필요하다.

이 비교는 V1에서 **한 번도 수행되지 않았다.** V1의 기준선은 랜덤 아날로그(N1), 5좌표
kNN(N2a), 직교화 잔차(N2b)였고, "이웃을 아예 쓰지 않는 합성지표"는 없었다.

부수 효과로 검정력이 좋아진다. V1 조건 3이 14/14 실패한 구조적 이유는 D와 N1의 날짜별 IC가
거의 무상관이라 paired 차이의 분산이 **오히려 커진 것**이었다(post-mortem §9.3, sd 비 중앙값
1.08). 아날로그와 B0는 같은 좌표에서 나오므로 날짜별 IC가 양의 상관을 가질 것으로 기대되고,
그만큼 paired 분산이 줄어든다. 다만 이 상관 rho는 **실행 전에 알 수 없으므로** 게이트 문턱은
rho에 의존하지 않도록 설계했고(§6), 실현 rho는 결과 문서에 의무 보고한다.

(5) 결과 이전 정의를 모두 만족한다. 완전한 수식은 계약문 §4에 있다.

| --- | --- | --- | --- | --- |

| 2 | Trend | `return_20` | 월 단위 방향과 강도 | 20 |
| 3 | Trend | `return_60` | 분기 단위 추세. 같은 20일 수익률도 60일 맥락이 다르면 다른 상태다 | 60 |

### 3.1 거래량 좌표의 근거와 반대 증거

근거 셋: (a) 위 사전가설, (b) V1 신호공간에 대해 직교함이 실측됨(post-mortem §5.3, S(q)와
`vol_ratio_20`의 날짜 내부 Spearman이 14검정 전부 |rho| <= 0.026), (c) 데이터 비용 0.

반대 증거도 기록한다. C-M V1은 거래량 급증을 후보 조건으로 썼고 방향성 알파가 없었다(GATE-C2
FAIL). C-4 F0에도 `rvol_20`/`volume_z_20`이 있었고 그 IC는 단기 반전의 재포장으로 해석됐다.
**이 저장소에서 거래량이 방향을 맞춘 적은 아직 없다.**

### 3.2 좌표 수를 늘려 맞추는 경로 금지

C-4가 같은 창에서 이미 측정했다. 등가중 Euclidean 위에서 좌표를 11 -> 22 -> 26 -> 37로 늘리면
IC가 단조 감소하고 F3-F0의 95% CI 하한이 -0.0071이다. 좌표 추가는 공짜가 아니다. 좌표 수와
정의는 checksum에 동결되며, 결과를 본 뒤 추가·삭제하지 않는다. ablation은 secondary로 사전등록한다.

### 3.3 52주 계열 제외

`distance_52w_high` 계열은 252세션 warmup이 필요하고, 그러면 평가일이 221일에서 **29일로
붕괴**한다(계약문 §9 표). C-4도 같은 이유로 선언 단계에서 제외했다. V2-A 좌표 예산의 상한은
**130세션**이며(계약문 §9), 채택한 좌표는 전부 60세션 이내다.

### 3.4 시장 상대강도 좌표를 뺀 이유 (설계상 증명)

요청문 §6.F는 PIT-safe한 market benchmark가 가능하면 상대강도 좌표 1~2개를 검토하라고 했다.
**채택하지 않는다. 선호가 아니라 항등식 때문이다.**

V2-A의 스케일링은 날짜별 횡단면 백분위 순위다(§4). 시장 수익률 `m_D`는 **그 날짜의 모든
종목에 대해 같은 상수**이므로

```text
rank_cs( return_20 - m_D ) = rank_cs( return_20 )     (모든 D에 대해 정확히 성립)
```

즉 공통 벤치마크 대비 상대강도 좌표는 순위 변환 뒤 `return_20` 좌표와 **수치적으로 동일한
좌표**이고, 거리·B0·IC 어디에도 아무 기여를 하지 않는다. 좌표 하나를 복제해 좌표 수만 늘리는
셈이다. 부수 이득으로 `source.py`에 지수 context column을 싣는 EXTEND가 **critical path에서
사라진다**(reuse matrix §3).

베타 조정 상대강도(`return - beta x market_return`)는 per-ticker 값이라 순위 불변이 아니지만,
beta 추정창이라는 새 자유도를 만든다. **V2-B 후보로만 기록**하고 V2-A에서는 쓰지 않는다.

섹터 상대강도는 종목 -> 섹터 PIT 매핑이 저장소에 없어 제외한다(참조 스냅샷 필드에 섹터가 없고,
SEC SIC는 현재값이라 PIT가 아니다).

## 4. Scaling / Similarity / K

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| Scaling | 날짜별 횡단면 백분위 순위 `(평균순위 - 1)/(n - 1)`, 그 날짜 전체 적격 유니버스 기준 | 이상치 강건, 단위 제거, PIT 안전(그날 정보만), rolling 추정창 없음. `features.percentile_rank`가 이미 구현·테스트됨 |
| Similarity | 순위 좌표 위 **등가중 Euclidean** | 자유도 0. `similarity.score_block` Euclidean 경로 그대로 |
| 금지 | learned/optimized weights, Mahalanobis, neural embedding, metric learning | 요청문 §10 |
| K | **50** (변경 없음) | V1 인프라 재사용, 결과 비교 가능, 새 자유도 없음. V1에서 K=50은 INSUFFICIENT_NEIGHBORS 0건으로 구조적 여유 확인 |

선언해 둘 부작용 하나: 백분위 순위는 **분포 모양 정보를 버린다.** "거래대금이 기준의 5배"와
"3배"가 둘 다 상위 1%면 같은 좌표값이 된다. 압축·확장 같은 꼬리 상태를 다루는 연구에서 이것은
실질적 손실이며, 단순성과 PIT 안전성을 위해 **인지한 채 선택**한 것이다. 원시값 기반 변형은
secondary ablation으로만 본다.

## 5. Primary Horizon = 5세션 (h = 5)

**선택 근거는 경제적 지평이며, V1의 horizon 결과는 근거에서 배제했다.**

1. 좌표의 정의창이 20/60세션이다. 20세션 창으로 읽은 상태는 그 창의 일부가 교체되는 동안만
   "같은 상태"로 남는다. h=5는 정의창의 25%, h=10은 50%다. h=10에서는 라벨 구간의 절반이
   이미 다른 상태에 속하므로 상태 -> 결과의 대응이 희석된다.
2. 거래 의도. B는 당일 청산(`B holds nothing overnight`), E0는 오버나이트다. D 계열이 채울
   자리는 **수일 단위 스윙**이고 h=5는 정확히 1거래주다.
3. 라벨 중첩. 연속 평가일 사이 라벨 중첩이 h=10의 절반이므로 날짜별 IC 시계열의 자기상관이
   작아지고 같은 221일에서 유효표본이 커진다.

Secondary horizon 1/3/10/20은 **기술통계로 전부 보고**하되 판정에 쓰지 않는다. 평가 구간은
secondary 최장 h=20을 수용하도록 V1과 같은 [260, 480]으로 고정한다(계약문 §9).

## 6. 판정 구조

Primary 가설 1개, Bonferroni 없음. FWER는 그대로 0.05이며, primary를 1개로 줄이는 것은
**개별 임계값을 낮추는 대신 기회를 13개 없애는 것**이라 완화가 아니다.

게이트의 완전한 조건과 수치는 계약문 §7에 있다. 설계 의도만 적는다.

```text
PASS       모든 조건 충족. 장기 데이터 구매 후보 = YES
BORDERLINE 점추정은 일관되게 양수이고 B0 대비 우위도 양수이나
           CI 또는 블록 안정성 중 정확히 하나가 기준에 미달. 구매 후보 = YES(조건부)
FAIL       그 외. Strategy D 연구 종료, D를 근거로 한 장기 데이터 구매 정당화 불가
```

BORDERLINE은 PASS 남발 수단이 아니다. **점추정이 음수이거나 B0 대비 열위이면 즉시 FAIL**이고,
조건 2개 이상이 미달이어도 FAIL이다.

이 게이트는 유의성 게이트가 아니라 **의사결정 게이트**다. 알파 승인에는 CI 하한 > 0이 필요하지만
구매 판단에는 "추적할 만한 흔적이 있는가"가 필요하며, 후자는 같은 표본에서 훨씬 높은 검정력을
갖는다. 대가는 높은 1종 오류(귀무 하에서 PASS 약 0.06~0.10, PASS+BORDERLINE 약 0.16~0.22)이고,
이 값은 계약문 §8에 명시된 근사 운영특성이다. 비대칭 비용(잘못된 PASS = 데이터 비용 + 추가 연구,
잘못된 FAIL = 연구선 영구 종료)을 감안한 의도된 선택이다.

## 7. PASS가 의미하지 않는 것

```text
PASS != 알파 존재
PASS != Backtester 승인
PASS != 실거래 승인
PASS  = 8년 이상 장기 데이터를 구매해 dev / validation / locked OOS를 분리 구축할 가치 있음
```

현재 2년 결과는 **Final OOS가 아니다.** `USB-HIST-V1`(2024-09 ~ 2026-09)은 D V1과 C-4가 이미
읽었고 V2-A가 세 번째로 읽는 창이므로, 이 창은 영구적으로 **development / screening data**로
표시하며 향후 locked OOS로 재사용하지 않는다(계약문 §12).

| 그 문서의 논거 | 현재 상태 |
| --- | --- |
| 검정력이 기대 효과와 같은 자리에 있다 (MDE 0.0109 vs 측정 최대 0.0177) | **유의성 게이트에 대해서는 여전히 사실이다.** V2-A는 유의성이 아니라 점추정·부호안정성 게이트로 판정하므로 탐지 한계가 달라진다(계약문 §8). 다만 검출 가능한 것은 **큰 우위뿐**이며, 작지만 진짜인 우위는 FAIL/BORDERLINE으로 떨어진다 |
| 평가 구간이 단일 레짐이다 (4블록 전부 상승, 연율변동성 11.6~15.5%) | **그대로 유효하다.** 어떤 결과에도 "저변동 상승장에서"라는 한정자가 붙는다. 레짐은 필터로 쓰지 않고 기술적 층화로만 본다(계약문 §6.4) |
| 같은 창이 이미 두 번 읽혔다 | **그대로 유효하다.** §7의 오염 표시로 대응하며, 이 창을 holdout으로 승격하지 않는다 |
| 구매 먼저, 연구 나중이 옳은 순서다 | **여기서 갈린다.** 그 문서는 "V2 PASS를 구매의 전제로 삼지 말라"고 했고 그 주장은 유지된다. 이번 스크리닝은 구매의 **전제조건이 아니라 입력**이다. FAIL이면 D를 근거로 한 구매가 정당화되지 않을 뿐, 다른 전략을 근거로 한 구매는 별개다 |

남는 위험을 숨기지 않는다: **저검정력 FAIL로 연구선을 닫을 위험**이다. 계약문 §8이 그 확률을
수치로 제시하고(진짜 우위 +0.008일 때 FAIL 확률 약 0.03~0.28), §11이 FAIL 시 닫는 범위를
"이 좌표계 + 이 데이터"로 한정한다.

## 9. 다음 단계

```text
D0 PASS  -> D-V2A-1  Data / PIT 사전검증 (V1 D1 재수행, 새 identity)
         -> D-V2A-2  구현 + 결정성 + PIT 감사
         -> D-V2A-3  Alpha firewall / 누출 검사
         -> D-V2A-4  SCREENING 판정
D0 FAIL  -> 착수하지 않음
```

D0 이후 단계는 별도 승인 없이 자동 진행하지 않는다.

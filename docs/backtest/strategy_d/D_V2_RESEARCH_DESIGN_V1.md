
## 1. V2가 답해야 할 질문의 재설계

### 1.1 V1의 질문

```text
"차트 모양이 비슷한가?"
= 최근 종가 경로가 가까운 이웃의 median 전방 초과수익이 순위 정보를 갖는가
```

### 1.2 V2 후보 질문

```text
"시장 구조가 비슷한가?"
= 추세/위치/변동성/거래량을 요약한 적은 수의 좌표가 가까운 이웃이 순위 정보를 갖는가
```

즉 아날로그의 단위를 `raw price path` 에서 `market-state feature vector` 로 옮기는 것이다.

### 1.3 이 이동이 새 질문인지 먼저 확인해야 한다

**상당 부분 이미 답이 있다.** 두 개의 독립 측정이 같은 데이터 창에 존재한다.

| 이미 측정된 것 | 어디 | 결과 |
| --- | --- | --- |
| 전 횡단면 + 5좌표 피처 kNN (Top-50, 같은 cap/embargo) | **D V1의 N2a** | IC +0.0038 ~ +0.0126 |
| 급등 후보 풀 + 11좌표 시장상태 kNN | **C-4 F0** | IC +0.0603, 단 `return_5d` 역부호 재포장 혐의 |
| 같은 풀 + 37좌표로 확장 | **C-4 F3** | +0.0224, F3 - F0 = **-0.0379 (유의 음수)** |

`baselines.n2a_signal`은 이름만 baseline일 뿐 **피처공간 아날로그의 완성된 구현**이다. 같은
`neighbor_search.select`, 같은 cap, 같은 embargo, 같은 median 신호에 거리만 표준화 5좌표
Euclidean이다. 즉 V2-A의 최소 형태는 **이미 14번 실행됐고**, 남은 차이는 좌표를 5개에서 8~12개로
늘리는 것뿐이다. 그리고 좌표를 늘렸을 때 어떻게 되는지는 C-4가 등가중 Euclidean 위에서
측정했다(단조 감소, F3-F0 CI 하한 -0.0071).

> 그러므로 V2-A를 "새 가설"로 부르려면, 좌표를 바꾸는 것이 아니라 **질문 자체를 바꿔야 한다**(§4).

## 3. 사전 경제 가설이 있는 feature family만 남긴다

"V1이 실패했으니 넣자"는 근거가 아니다. 각 좌표에 **먼저** 경제적 가설을 요구한다. 가설이 없으면
좌표도 없다.

| Family | 좌표 (후보) | 사전 가설 | 판정 |
| --- | --- | --- | --- |
| **F1 Trend** | `return_5`, `return_20`, `return_60` | 수익률의 시간 구조는 수급의 지속/소진을 구분한다. 같은 20일 수익률도 최근 5일에 몰렸는지 고르게 났는지가 다르다 | **포함** |
| **F2 Position** | `dist_to_20d_high`, `dist_to_60d_high` | 고점 근처는 매물대가 얇고 저점 근처는 두껍다. 같은 추세라도 구간 내 위치에 따라 전방 분포가 다르다 | **포함** |
| **F3 Volatility structure** | `rv_20 / rv_60` (수축비), `TR(D) / ATR_14` (당일 확장) | 변동성은 군집한다. 수축 구간과 확장 구간은 서로 다른 상태다 | **포함하되 §8** |
| **F4 Volume structure** | `V(D) / meanV(D-20..D-1)`, `dollar_volume_20 / dollar_volume_60` | **가격이 압축될 때 거래량도 함께 수축하면 공급 감소이고, 가격만 압축되고 거래량이 유지되면 분산이다.** 두 상태의 전방 분포는 같을 이유가 없다 | **포함** |
| **F5 Compression** | `range_20 / range_60`, 종가 표준편차 / ATR | 압축은 위 둘의 결합 상태이며 단일 좌표로 요약하면 결합이 사라진다 | **1좌표만 포함** |
| **F6 Relative / Market** | `return_5 - SPY_return_5`, `return_20 - SPY_return_20` | 같은 +10%도 시장이 +8%일 때와 -2%일 때 의미가 다르다 | **포함 (EXTEND 필요)** |
| F6b Sector | - | 매핑 없음 | **제외** (§2) |
| F7 Market regime | - | 평가 구간에 변동 없음 | **좌표 아님** (§14) |

합계 **10~12좌표**. 요청문 §7의 상한(8~15)을 지킨다.

### 3.1 좌표 수를 늘려 성능을 맞추는 경로 금지

C-4가 같은 창에서 이미 측정했다: 등가중 Euclidean 위에서 좌표를 11 -> 22 -> 26 -> 37로 늘리면
IC가 **단조 감소**하고 F3 - F0의 95% CI 하한이 -0.0071이다. 좌표 추가가 공짜가 아니라는 실측
증거가 있으므로, V2 선언은 좌표 수를 **동결하고 ablation을 사전등록**해야 한다.

## 4. Raw shape를 어떻게 다룰 것인가

| Option | 내용 | 평가 |
| --- | --- | --- |
| **A** | Raw shape 완전 제거, 구조 좌표만 | V1과 **입력이 겹치지 않는다**. V1 파라미터 튜닝으로 오해될 여지가 없다. 단 §1.3대로 N2a의 확장이라는 다른 오해가 생긴다 |
| B | 구조 좌표가 primary, shape는 secondary | 두 신호의 결합 방식(가중치)이 새 자유도가 된다. 결과를 보고 가중치를 정하면 그 순간 사후최적화 |
| C | shape + 구조 joint distance | **V1 파라미터 tweak에 가장 가깝다.** "경로에 좌표를 더했더니 됐다"는 결과는 해석 불가능하고, C-4가 좌표 추가의 부작용을 이미 측정했다 |

**결정: Option A.** B와 C는 둘 다 결합 가중치라는 자유도를 새로 만들고, 그 자유도를 결과를 보지
않고 고정할 원리가 없다. V1 FAIL 이후 가장 피해야 할 것이 "V1에 무언가를 더해 살리는" 형태다.

## 5. 그런데 Option A만으로는 새 가설이 아니다

§1.3의 문제가 남는다. 구조 좌표 kNN은 N2a의 좌표 확장판이고, 좌표 확장의 효과는 C-4가 이미
음수로 측정했다. 그대로 가면 V2는 "N2a에 좌표 몇 개 더한 것"을 14번 재실행하는 연구가 된다.

V2가 **진짜로 새로운 것을 묻는** 방법은 좌표가 아니라 **비교 대상**을 바꾸는 것이다.

```text
V1 primary:  아날로그 IC > 0 인가, 그리고 랜덤 아날로그를 넘는가
V2 primary:  아날로그가 "같은 좌표를 그냥 합성한 지표"를 넘는가
```

이 질문이 중요한 이유:

1. **메커니즘을 직접 겨눈다.** Historical Analog의 주장은 "좌표가 좋다"가 아니라 "과거 유사 사례의
   실현 분포가 선형 결합보다 많은 것을 담는다"이다. 비선형성, 상호작용, 조건부 분포가 그 주장의
   내용이다. 같은 좌표의 등가중 순위 합성지표를 이기지 못하면 **아날로그 기계 전체가 불필요**하다.
2. **V1에서 한 번도 검정되지 않았다.** V1의 기준선은 랜덤 아날로그(N1)와 피처 kNN(N2a)과
   직교화(N2b)였다. "이웃을 아예 쓰지 않는 합성지표"는 기준선에 없었다.
3. **검정력이 좋다.** V1 조건 3이 14/14로 실패한 구조적 이유는 D와 N1의 날짜별 IC가 거의
   무상관이라 paired 차이의 분산이 오히려 커졌기 때문이다(post-mortem §9.3, sd 비 중앙값 1.08).
   아날로그와 합성지표는 **같은 좌표에서 나오므로 날짜별 IC가 강하게 양의 상관**일 것이고, paired
   차이의 분산은 그만큼 줄어든다. 같은 표본에서 더 작은 효과를 잡을 수 있는 유일한 설계 개선이다.
4. **FAIL이 값지다.** "좌표를 바꿔도 아날로그는 합성지표를 넘지 못한다"는 결과는 좌표계 하나가
   아니라 **Historical Analog 계열 전체를 닫는다.** V1 FAIL은 그만큼을 닫지 못했다.

이것이 §0에서 V2-A를 "primary = 아날로그가 동일 좌표 합성지표를 넘는가"로 정의한 이유다.

## 6. Volume 포함 여부

**포함.** 단 근거는 "V1에 없었으니까"가 아니라 아래 세 가지다.

1. **사전 경제 가설이 있다.** §3 F4. 압축 + 거래량 수축 = 공급 감소, 압축 + 거래량 유지 = 분산.
   이 구분은 가격만으로는 표현되지 않는다.
2. **V1 신호공간에 대해 직교한다.** post-mortem §5.3 실측: S(q)와 `vol_ratio_20`의 날짜 내부
   Spearman이 14검정 전부 |rho| <= 0.026이다. 경로 좌표는 거래량 정보를 **전혀** 담고 있지 않다.
3. **데이터 비용 0이다.** grouped daily에 이미 있고, 유동 종목 행에서 volume <= 0인 경우가 0건이다.

반대 증거도 기록한다. C-M V1은 거래량 급증을 후보 조건으로 썼고 방향성 알파가 없었다(GATE-C2 FAIL,
C-V2B는 그것을 변동성 탐지로 재분류했다). C-4 F0에도 `rvol_20`, `volume_z_20`,
`dollar_volume_change_5d`가 들어 있었고 F0의 IC는 단기 반전의 재포장으로 해석됐다. 즉
**거래량이 새 정보인 것은 맞지만, 이 저장소에서 거래량이 방향을 맞춘 적은 아직 없다.**

## 7. PIT / 정확성 주의사항 (거래량과 분할)

### 7.1 `Panel.volume`은 원시 주식 수다

분할 조정은 가격에만 `F(t)`로 들어간다. 1:10 병합 직후 거래량은 10분의 1로 보이며, 순진한
"거래량 수축" 좌표는 이것을 극단적 수축으로 읽는다.

### 7.2 lookback 60세션 이하면 유니버스 규칙이 이미 막아 준다

D0 `universe.corporate_action_exclusion`은 `(D-60, D]` 구간에 분할이 있는 ticker-date를 **query와
library 양쪽에서 제외**한다(D1 실측 SPLIT_WINDOW 5,067건). 따라서 lookback이 60세션을 넘지 않는
좌표는 창 안에 분할이 존재할 수 없고 원시 거래량을 그대로 써도 된다.

**60세션을 넘는 거래량 좌표를 쓰려면 `V * F` 변환을 선언에 명시해야 한다.** V2의 좌표 예산이
60세션 이내라면(§13) 이 문제는 자동으로 사라진다.

## 8. Volatility의 역할 결정

세 후보 중 무엇으로 쓸 것인가.

| 후보 | 채택 여부 |
| --- | --- |
| similarity 좌표 | **부분 채택** (§3 F3, 수축비와 당일 확장 2좌표만) |
| control variable | **채택, 그리고 이것이 핵심이다** |
| regime variable | 평가 층화로만 (§14) |

### 8.1 왜 control이 핵심인가

같은 창에서 세 연구가 독립적으로 같은 것을 관찰했다.

```text
D V1  W40_H10_B 분위표: Q1과 Q5 양끝에서 MFE/MAE가 함께 커지는 U자
C-4   F3 분위표: 예측값이 가장 낮은 Q1이 MFE 최대(+0.124), MAE 최심(-0.104)
C-V2B C-M이 탐지하는 것은 방향이 아니라 변동성 확대 (3/3 변형, 4/4 구간)
```

즉 **아날로그 예측값은 방향이 아니라 변동성에 정렬하는 경향이 있다.** 이것을 좌표로 흡수하려는
시도는 C-4가 이미 해 봤고(D일 True Range와 ATR 확장을 좌표에 넣음) 흡수되지 않았다.

### 8.2 설계적 대응: 응답변수를 변동성 중립화한다

좌표를 더하는 대신 **측정 대상**을 바꾼다.

```text
V1 label:  excess_return_h = close_return_h - (그날 유니버스 median)
V2 후보:   vol_normalized_excess_h = excess_return_h / rv_pred
           rv_pred = D 시점까지 정보로만 만든 변동성 예측 (예: rv_20 또는 ATR_14 / P)
```

효과: **변동성 순위만 재는 신호는 IC가 0으로 수렴한다.** 변동성이 큰 종목이 양쪽으로 크게 움직여서
생기는 순위 정보가 분모에서 상쇄되기 때문이다. 세 연구가 반복해서 만난 confound를 설계 단계에서
제거하는 유일한 방법이고, 결과를 보고 만든 조정이 아니라 **세 개의 독립 관찰에 대한 선행 대응**이다.

주의: 이것은 V1과 **다른 응답변수**다. 따라서 V2의 IC를 V1의 IC와 직접 비교할 수 없으며, 선언에
그 사실을 명시해야 한다. 원 excess_return_h에 대한 IC는 secondary로 함께 보고한다.

## 10. Similarity metric

| 후보 | 평가 |
| --- | --- |
| **표준화 Euclidean (백분위 순위 좌표 위, 등가중)** | **채택.** 좌표가 이미 날짜별 백분위 순위라 스케일이 [0,1]로 통일돼 있다. 자유도 0. `similarity.score_block`의 Euclidean 경로와 `baselines.n2a_signal`이 그대로 쓴다 |
| Mahalanobis | 기각. 공분산 추정이 필요하고, PIT를 지키려면 rolling 추정이 되어 **움직이는 부품**이 하나 늘어난다. 추정창 길이가 새 자유도다 |
| weighted Euclidean | 기각. 가중치 최적화는 요청문과 V1 정신에 정면으로 어긋난다. 등가중이 아니려면 가중치가 **데이터 이전에** 정당화돼야 하는데 그런 근거가 없다 |
| cosine | 기각. 순위 좌표에서 원점이 의미를 갖지 않아 해석이 어렵다 |

**결론: 가장 단순하고 설명 가능한 것이 primary다.** 등가중 표준화 Euclidean.

## 11. Feature scaling

| 후보 | 평가 |
| --- | --- |
| **날짜별 횡단면 백분위 순위 `(평균순위 - 1)/(n - 1)`** | **채택.** V1 N2가 이미 쓰는 방식이고 `features.percentile_rank`가 구현·테스트돼 있다. PIT 안전(그날 정보만), 횡단면 비교 가능, 이상치에 강건, 좌표간 스케일 통일 |
| historical rolling z-score | 기각. 추정창이 새 자유도, 이상치에 취약 |
| robust median/IQR | 기각. 백분위 순위의 하위호환 |
| rank transform (동일) | 채택안과 같은 것 |

부작용 하나를 선언해야 한다: 백분위 순위는 **분포 모양 정보를 버린다.** "거래량이 평균의 5배"와
"3배"가 둘 다 상위 1%면 같은 좌표값이 된다. 압축/확장 같은 꼬리 상태를 다루는 연구에서 이것은
실질적 손실이다. V2 선언은 이 손실을 인지한 상태에서 **단순성을 선택한 것**임을 명시하고, 원시값
기반 변형은 사전등록된 secondary ablation으로만 본다.

### 13.3 검정력이 진짜 걸림돌이다

post-mortem §3.3의 MDE(이 데이터, 221 평가일, 실측 부트스트랩 SE 기준):

### 13.4 장기 데이터는 V2 **전에** 필요한가

**필요하다.** 순서가 중요하다.

| 순서 | 문제 |
| --- | --- |
| V2 먼저 -> PASS 나면 구매 | PASS가 나올 확률이 낮고(§13.3), 설령 나와도 그 PASS는 이미 두 번 본 창에서 나온 것이다. 구매한 과거 데이터를 OOS로 쓰려 해도, **2024-2026 창에서 얻은 모든 관찰이 이미 설계에 스며 있다** |

성립한다. 선언문에 이 논리를 적고, 나머지 13칸은 **secondary로 전부 보고**한다.

## 15. Baseline 설계

V1보다 **더 엄격해진다.**

| 기준선 | 역할 | V1 대비 |
| --- | --- | --- |
| **B0 Rank Composite** | 같은 좌표의 등가중 순위 합성지표. 이웃을 쓰지 않는다 | **신규. V2의 primary 비교 대상** |
| B1 Random Analog | 같은 라이브러리·변동성 분위 매칭 무작위 추출 | V1 N1과 동일, 단 **secondary로 강등** |
| B2 Simple Factor kNN | V1의 5좌표 kNN | V1 N2a와 동일. 좌표 확장의 순효과 측정용 |
| B3 Orthogonalized | 좌표에 직교화한 잔차 IC | V1 N2b와 동일 |

### 15.1 왜 B1을 primary에서 내리는가

**완화가 아니라 통계적 설계 원리 때문이다.** post-mortem §9.3이 측정한 사실: D와 N1의 날짜별 IC가
거의 무상관이라 `sd(IC - IC_N1)`이 `sd(IC)`보다 13/14에서 **크다**(중앙값 1.08배). paired 검정의
목적은 공통 변동을 제거해 분산을 줄이는 것인데, 이 조합에서는 정반대로 작동한다. 즉 V1 조건 3은
**pairing의 이득 없이 두 신호의 분산을 합산한 검정**이었다.

B0는 다르다. 아날로그와 합성지표는 **같은 좌표에서 나오므로 날짜별 IC가 강하게 양의 상관**이고,
paired 차이의 분산이 실제로 줄어든다. 같은 표본으로 더 작은 효과를 잡는다.

B1은 그대로 계산해 보고한다. 다만 gate의 primary 조건이 아니라, **B1 대비 우위가 없으면 그 사실을
결과 문서에 명시**하는 secondary 조건으로 둔다. 이것이 "V1이 빡셌으니 빼자"가 아님을 보이는
근거는 두 가지다. (1) B0 조건이 B1 조건보다 **넘기 어렵다**(합성지표의 IC가 랜덤 아날로그의 IC보다
높을 것이므로). (2) 근거가 V1의 FAIL이 아니라 paired 검정의 분산 구조라는 일반 원리다.

## 17. Gate 및 다중검정 설계

### 17.1 V1 조건의 재검토

각 조건이 왜 필요했는지, 통계적으로 중복이었는지를 본다. **V1 결과가 아니라 검정 설계 원리가
근거여야 한다.**

| V1 조건 | 유지/수정 | 근거 |
| --- | --- | --- |
| 1 IC point > 0 | **유지** | 조건 2에 포함되는 중복이지만 비용 0이고 방향 선언 역할을 한다 |
| 2 IC CI low > 0 | **유지** | 핵심 |
| 3 vs N1 CI low > 0 | **secondary로 이동** | §15.1. pairing이 분산을 늘리는 구조. 대신 B0 조건이 들어온다 |
| **신규 vs B0 CI low > 0** | **추가** | §5. 메커니즘을 직접 겨누는 조건 |
| 4 N2b 잔차 CI low > 0 | **유지** | 단순 피처 잉여성 차단 |
| 5 vs N2a point > 0 | **CI 조건으로 강화** | point 조건은 통계적 내용이 거의 없다. **완화가 아니라 강화** |
| 6 Q5 - Q1 > 0 | **유지** | IC는 순위 상관이라 경제적 크기를 말하지 않는다. 분위 스프레드가 그 역할 |
| 7 time blocks >= 3/4 | **유지** | 구간 안정성 |
| 8 horizon consistency | **대체** | primary가 1개가 되면 이 조건이 정의되지 않는다. 대체물: **secondary 13칸 전수 보고 + 부호 일관성 기술** |
| 9 sample | **유지** | 값도 그대로 (>= 150일, >= 20,000 query, >= 1,000 ticker, INSUFFICIENT <= 0.05) |
| 10 PIT violations == 0 | **유지** | 타협 불가 |

순효과: 조건 하나가 secondary로 내려가고(3), 더 어려운 조건 하나가 들어오고(B0), 하나가
강화된다(5). **전체적으로 완화가 아니다.**

### 17.2 다중검정 방식

| 방식 | 평가 |
| --- | --- |
| Bonferroni over 14 유지 | 14 검정이 서로 독립이 아니다(같은 표본, 겹치는 창, 겹치는 horizon). Bonferroni는 독립 가정에서 보수적이고, 종속이면 **과하게** 보수적이다 |
| Holm | Bonferroni보다 균일하게 강력하고 가정이 같다. 그러나 "14개 중 아무거나 하나 통과"라는 **해석 문제**는 그대로 남는다 |
| hierarchical / gatekeeping | primary가 통과해야 secondary를 검정. primary가 1개면 자연스럽게 이 구조가 된다 |
| **primary 1개 사전지정 + secondary 기술통계** | **채택** |

**채택 근거(V1 결과와 무관한 설계 원리):**

1. family-wise error rate는 어느 쪽이든 0.05다. primary를 1개로 줄이는 것은 **FWER를 완화하지
   않는다.** 개별 검정 임계값이 낮아지는 대신 **기회가 13개 사라진다.**
2. 사전가설이 명확해진다. "14개 중 하나라도 통과하면 PASS"는 연구 질문이 14개라는 뜻이고, 그
   자체가 가설이 뾰족하지 않다는 신호다.
3. 해석이 쉬워진다. V1은 PASS했더라도 "어느 조합이 진짜인가"를 답할 수 없었다.

**절대 금지:** 결과를 보고 primary를 고르는 것. primary는 D0 선언문의 checksum 안에 들어가고,
선언 시점에 그 선택의 **경제적 근거**가 문장으로 적혀 있어야 한다(§14).

## 18. OOS 설계

V2가 사전검증을 통과해도 **같은 2년 데이터에서 계속 최적화하는 경로는 없다.** 지금 설계해 둔다.

```text
Development period  : 개발·선언·디버깅에 쓰는 구간
Holdout period      : 선언 후 단 1회만 여는 구간
Long OOS period     : 레짐이 다른 장기 구간
```

### 18.1 현재 확보 가능한 것

| 구간 | 현재 상태 |
| --- | --- |
| Development | USB-HIST-V1 221 평가일. **단 V1과 C-4가 이미 두 번 본 창이다** |
| Holdout | **없음.** 같은 창을 쪼개는 것은 holdout이 아니다(레짐이 하나이므로 §9.1) |
| Long OOS | **없음.** rolling 2년 plan으로는 2024-09 이전을 받을 수 없다 |

### 18.2 전방 누적이라는 공짜 경로

수집을 계속하면 평가일이 **월 약 21세션**씩 쌓인다.

```text
V1 평가 구간과 같은 221일을 새로 확보하려면  약 10.5개월  (2027-08 무렵)
조건 9의 하한 150일                          약 7.1개월   (2027-05 무렵)
"미사용 평가일 200일"                        약 9.5개월   (2027-07 무렵)
```

freeze는 파일을 로컬에 보존하므로, provider의 rolling 창이 앞을 잘라내도 **이미 받은 과거는
사라지지 않는다.** 즉 전방 누적은 비용 0이고 시간만 든다.

### 18.3 권장 구조

```text
장기 데이터 구매 -> 과거 구간에서 개발/선언
                 -> USB-HIST-V1(2024-2026)은 이미 오염됐으므로 holdout으로 쓰지 않는다
                 -> 전방 누적분을 frozen external OOS로 단 1회 개봉
```

"V2 prevalidation PASS 후에만 구매"는 §13.4의 이유로 권장하지 않는다.

## 20. 권고와 최종 판단

### 20.1 하나만 고른다면 V2-A

```text
RECOMMENDED V2 CANDIDATE: V2-A  Market Structure Analog
                          primary = 아날로그가 동일 좌표 합성지표(B0)를 넘는가
```

근거(요청문 §25의 기준 순서대로):

| 기준 | V2-A |
| --- | --- |
| 경제적 설명력 | 12좌표 전부 사전 가설을 갖는다. 거래량 좌표는 V1 신호공간에 직교함이 실측됐다(|rho| <= 0.026) |
| V1과의 독립성 | 입력·비교대상·응답변수 세 축이 모두 다르다. Option A로 경로를 완전히 제거한다 |
| PIT 가능성 | 전 좌표 lookback <= 60세션. V1의 PIT 장치를 그대로 상속한다 |
| 현 데이터 사용 가능성 | 계산은 가능. **결론은 불가**(§13.3) |
| 복잡도 | 신규 코드 약 300~400줄. 인프라 5,284줄 중 111줄만 폐기 |
| 검증 비용 | V1과 동급 |
| 과최적화 위험 | 가중치 0, 문턱 0, 좌표 수 동결, ablation 사전등록 |
| **FAIL의 가치** | 아날로그 메커니즘이 합성지표를 못 넘는다는 결과는 **좌표계 하나가 아니라 계열 전체를 닫는다** |

### 20.2 그럼에도 지금은 하지 않는다

```text
V2 VALUE OF INFORMATION (현재 데이터 기준): LOW
FINAL DECISION: DO NOT PROCEED
```

세 가지가 동시에 성립하기 때문이다.

1. **검정력이 기대 효과와 같은 자리에 있다.** MDE 0.0109~0.0133 vs 이 저장소 최고 측정치 0.0126~0.0177.
   가장 가능성 높은 결과는 "점추정 양수, CI가 0 포함"이고, 그것은 가설에 대해 거의 아무것도
   말해 주지 않는다(§13.3).
2. **평가 구간이 단일 레짐이다.** 네 블록 전부 상승, 변동성 11.6~15.5%. 어떤 결과가 나와도
   "저변동 상승장에서"라는 한정자를 뗄 수 없다(§9.1, post-mortem §11).
3. **같은 창이 이미 두 번 읽혔다.** D V1과 C-4가 각각 이 창에서 아날로그 계열을 측정했고, 그
   관찰이 V2 설계에 이미 스며들어 있다(post-mortem §10.2). 세 번째 통과는 증거로서의 무게가
   더 가볍다.

**연구가 막힌 지점은 아이디어가 아니라 데이터다.** 이 상태에서 가장 정보가치가 높은 행동은 또
하나의 저검정력 연구가 아니라 **데이터 결정**이다.

### 20.3 재개 트리거 (둘 중 하나 충족 시 V2-A D0 착수)

```text
T1  장기 히스토리 확보
    - 8년 이상, 최소 2개의 뚜렷이 다른 변동성 레짐 포함
    - development 구간과 holdout 구간을 물리적으로 분리 가능
    - USB-HIST-V1(2024-2026)은 오염 구간으로 표시하고 holdout으로 쓰지 않는다

T2  전방 데이터 누적
    - V1/C-4가 보지 않은 평가일 200일 이상 (월 약 21세션 -> 약 9.5개월, 2027-07 무렵)
    - 수집 지속만 하면 비용 0
    - 단 레짐 문제(§9.1)는 해결되지 않는다. T2는 T1의 대체가 아니라 차선이다
```

T1이 본선이고 T2는 차선이다. 둘 다 충족되지 않은 상태에서 V2-A를 돌리는 것은, 결과가 나오기
전에 이미 결론을 알 수 있는 연구를 수행하는 것이다.

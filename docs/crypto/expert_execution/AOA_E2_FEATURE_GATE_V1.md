## LOW_LEVERAGE: 연구 후보

- 근거: 최고 레버리지 3분위별 파국(ROE ≤ -5%) 비율 0.7 / 3.5 / 11.6%, 청산 episode의 79%가 최상위. 연도 안에서도 같은 기울기.
  계좌는 자본이 커지며 주문/자본을 1.41배(2018) → 0.15배(2021), 최고 노출/자본을 3.44 → 0.78배로 줄였다.
- 한계: 상관이다. 레버리지를 낮춘 시기와 계좌·시장이 변한 시기가 겹친다. 생존편향도 있다.
- US-B 연결: 이미 D4.1 safe sizing이 있다. 새 기능이 아니라 **기존 상한이 AOA 2019~2021 수준(최고 노출/자본 중앙 0.8 ~ 1.0, p90 1.9 ~ 3.0)과 비교해
  어디에 있는지 확인하는 문서**가 다음 단계다. 코드 변경 없이 가능하다.

## PARTIAL_CLOSE: 보류

- 규칙상 SUPPORTED이고 게이트도 형식상 통과했다.
- 그러나 판정을 만든 MAE 개선(+7.18%p)의 대부분은 CF3 설계에서 온다. "ADD는 그대로, REDUCE만 생략"하면 줄였다 다시 늘리는 episode에서 CF 포지션이
  실제 최대의 최대 9.4배까지 커진다.
- 포지션이 부풀지 않은 721 episode(탐색용)에서는 MAE +0.34%p [+0.21, +0.51], 수익 -0.52%p [-0.74, -0.26]. **위험 감소는 작고 수익 희생은 유의하다.**
- 부분청산 뒤 가격은 평균적으로 포지션에 유리하게 더 갔다(4h +0.17%). 역할은 위험 축소다.
- 권고: US-B에 구현할 근거로 쓰지 않는다. 다시 보려면 "크기를 맞춘 CF"(실제 포지션 상한을 넘지 않는 NO-PARTIAL)를 새로 사전등록해야 한다.

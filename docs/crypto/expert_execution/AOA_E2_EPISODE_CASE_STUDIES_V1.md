# AOA E2 Episode Case Studies V1

작성 2026-09-27. 계약 `AOA_E2_POSITION_MANAGEMENT_CONTRACT_V1.md` 10절 O (기술 통계, 판정 제외).
시각은 UTC. ROE·MAE·MFE는 episode 시작 자본 대비. 레버리지 = |포지션| / mid / 자본. XBTUSD만 시장경로가 있다.
원본: `data/research/expert_execution/e2/episode_metrics.parquet`, `add_events.parquet`, `reduce_events.parquet`.
잔액은 wallet `amount` 누적(날짜 D = [D-1 12:00, D 12:00) 정산 반영 후).

## 1. 2018-09-21: 계좌 리셋

| 항목 | 값 |
|---|---|
| 잔액 | 09-20 16.55 → 09-21 18.67 → **09-22 2.93 XBT** (전날 대비 -84%) |
| 회복 | 2018-10-15 (24일) |
| XBTUSD episode | 1개 (ep1763, 숏, 09-14 08:08 → 09-21 15:18, 175시간): **ROE +7.27%, 이익** |
| 실제 손실원 | XRPU18(만기 선물) 청산 3건 포함 -13.6 XBT, ETHUSD 롱·숏 왕복 (E0 `drawdown_case_studies.json`). **시장경로 없음** |

ep1763 (참고, 이익 episode): 최초 1계약 → 09-14 09:02 ~ 21:23 사이 25만 계약씩 ADD 10회, 레버리지가 ADD마다 약 2배씩 올라 최대 6.5배,
09-14 09:38부터 11회 부분청산(비율 중앙 62%, 평단보다 38bp 유리). MAE -0.7%, MFE +11.3%.

**평소와 다른 점**: 이 날의 파국은 XBTUSD 관리가 아니라 **소형 알트 만기 선물**에서 났고, 자본이 18 XBT인 시기에 한 episode 레버리지가 6배를 넘었다.
2019년 이후 알트 선물 비중은 급감했다(E0 5절).

## 2. 2021-05-05: 추세 역행 숏 물타기

**주 손실 ep3005** (숏, 04-26 01:09 → 05-04 16:07, 207시간, 시작 자본 750 XBT)

| 단계 | 내용 |
|---|---|
| 최초 | 102.5만 USD (레버리지 0.03) |

| 04-26 20:29 ~ 05-01 | 가격이 51,000 → 58,000으로 상승. 그 사이 ADD 12회, **평단보다 325 ~ 889bp 불리한 가격**에서 숏 추가 (평가손 -2.3 ~ -7.5%) |
| MAE | **-12.1%** (04-26 20시경) |
| 부분청산 | 24회 (비율 중앙 18%) |

| 결과 | 05-04 16:07 반전, **ROE -3.24%, -24.3 XBT** |
| 이어진 ep3007 | 숏, 30시간, MAE -2.3%, ROE -1.47%, -11.0 XBT |

**평소와 다른 점**: 성공 episode의 마지막 ADD는 평단 근처(중앙 -1bp)인데, 이 episode는 수일에 걸쳐 평단보다 수백 bp 불리한 곳에서 계속 추가했다.
다만 레버리지는 2배 안쪽이라 -12% 역행을 견뎠다.

## 4. 세 사건의 공통점과 차이

| 항목 | 2018-09-21 | 2021-05-05 | 2021-05-19 | 성공 episode 전형 |
|---|---|---|---|---|
| 손실원 | 알트 만기 선물 | XBTUSD 숏 장기 보유 | XBTUSD 롱·숏 연속 | |
| 불리한 가격 ADD | (시장경로 없음) | 평단 -325 ~ -889bp | 평단 -218 ~ -647bp | 마지막 ADD 평단 -1bp |
| 최고 레버리지 | 6.5 (XBTUSD) | 2.2 | 1.9 ~ 3.0 | 2.0 |
| 청산 | 3 (XRPU18) | 0 | 0 | 0 |
| 자본 피해 | -84% | -15% | -43% | |
| 회복 | 24일 | 22일 | 6일 | |

세 사건 모두 **평가손이 커지는 방향으로 ADD를 반복**했다. 계좌를 살린 차이는 레버리지다: 2018년에는 소자본에 고레버리지·청산으로 리셋됐고,
2021년에는 같은 행동을 2 ~ 3배 레버리지 안에서 해서 살아남았다.

## 0. 왜 방법을 바꾸는가

D5 / D5.1 / D5.2는 주요 셀 1,980개를 탐색해 **SURVIVE 0**이었다. D6는 그중 가장 유망했던 구조를
실행 가능한 전략으로 만들어 **D6-C FAIL**이었다.

D6-C가 남긴 결정적 사실:

| 연구 | 보고한 것 | D6-C 실측 |
|---|---|---|
| D5.1 11절 | 고변동성 gross **+34.15bp** | 고변동성 gross **+2.28bp** (중변동성 +7.09보다 나쁨) |
| D5·D5.1·D5.2 | BEAR에서 가장 강함 | BEAR net **-15.33bp**로 최악 |
| D5.2 C1 | net **+19.28bp** | 같은 계열 실행 net **-5.66bp** |

**bar 단위 조건부 미래수익률은 실행 가능한 거래 곡선이 아니었다.** D5 결과 문서 한계 L1이 경고한 내용이
수치로 확인됐다.

따라서 이번 연구는 탐색 정본 단위를 **bar-level conditional return → executable event trade**로 바꾼다.
셀을 수천 개 만들어 미래수익률이 높은 것을 고르지 않는다. 사건을 정의하고, 묶고, 실제로 집행한 뒤,
**그 거래 곡선 자체로 판정한다.**

## 2. COST-FIRST 원칙

왕복 taker 비용은 **11.25bp**다(D6-C 실측: 수수료 11.0bp + spread·funding 0.25bp).

이번 연구는 5~10bp 수준의 미세한 효과를 후보로 만들지 않는다. **드물어도 좋고, 빈도가 낮아도 좋고,
보유가 길어도 좋다. 대신 한 사건의 관측 가능한 변위가 비용보다 충분히 커야 한다.**

### 2.1 Cost-First 스크린 (결과 보기 전 적용)

> **이벤트의 median 변위 크기 ≥ 왕복 비용의 6배 (67.5bp)**

근거 산술(결과가 아니라 설계):
- SURVIVE는 edge/cost ≥ 2.0을 요구한다(9절) → 필요한 gross = 22.5bp
- 평균회귀 전략이 변위의 1/3을 초과해 가져간다고 가정하지 않는다
- 따라서 필요한 변위 = 22.5 x 3 = **67.5bp = 비용의 6배**

이 스크린은 **feature 크기만 보고 적용**하며, 통과하지 못한 family는 백테스트하지 않는다.

## 5. Feature 정의 (동결)

`C` = perp 1m 종가, `IDX` = index 1m 종가, `OI` = PIT 규칙(기록+5분)으로 알려진 OI.
모든 창은 bar `t`를 포함해 과거로 센다. NaN은 0으로 채우지 않는다.

| id | 공식 | 의미 |
|---|---|---|
| `disp15` | `ln(C[t] / C[t-15])` | 15분 가격 변위 |
| `oichg15` | `ln(OI[t] / OI[t-15])` | 15분 OI 변화 |
| `basis` | `ln(C[t] / IDX[t])` | perp-index 괴리 |
| `rv15` | `std(ln(C/C[-1]), t-14..t)`, ddof 0 | 15분 실현변동성 |
| `rv1440` | `std(ln(C/C[-1]), t-1439..t)`, ddof 0 | 24시간 실현변동성 |
| `volratio` | `rv15 / rv1440` | **변동성 팽창 비율** |

### 5.1 정규화 — robust z (동결)

```
day D의 z = (x - median_30d) / (1.4826 * MAD_30d)
median_30d, MAD_30d = [D-30일, D) 의 유한값으로 계산
유효값이 30일 창의 50% 미만이면 z = NaN
```

D5의 bucketize와 **같은 PIT 구조**(전날까지 30일)이되 분위수 대신 median/MAD를 쓴다.
이유: 이번 연구는 **꼬리**를 정의해야 하는데, 분위수 버킷(하위 10%)은 꼬리를 해상하지 못한다.
MAD 기반 z는 꼬리에 강건하고 "몇 시그마"라는 경제적 표현을 그대로 쓸 수 있다.

`volratio`는 이미 비율이므로 z를 적용하지 않고 **원값에 임계값**을 건다.

## 6. Event 정의 (동결, 4개 후보)

E2는 3절에서 탈락했으므로 실행 후보는 **4개**다.

| id | family | 방향 | 조건 | OOS 이벤트 | median 변위 |
|---|---|---|---|---|---|
| **C1** | E1 | **LONG** | `z(disp15) ≤ -10.0` **및** `z(oichg15) ≤ -2.5` | 259 | 167.9bp (14.9x) |
| **C2** | E1 | **SHORT** | `z(disp15) ≥ +10.0` **및** `z(oichg15) ≤ -2.5` | 238 | 166.0bp (14.8x) |
| **C3** | E3 | **LONG** | `z(disp15) ≤ -5.0` **및** `volratio ≥ 4.0` | 207 | 127.7bp (11.4x) |
| **C4** | E4 | **LONG** | `z(disp15) ≤ -6.0` **및** `z(oichg15) ≤ -2.0` **및** `z(basis) ≤ -2.0` | 224 | 137.7bp (12.2x) |

각 후보의 임계값은 4절 T3 규칙의 결과다. 더 극단적인 값은 표본 하한을 통과하지 못했다
(C3는 `z ≤ -6`에서 연도별 18건, C4는 `z ≤ -7`에서 174건).

### 6.1 시장 가설

**C1 - 강제 디레버리징 후 정상화 (LONG)**
> 15분 안에 10시그마 급락이 일어나고 **동시에 미결제약정이 줄어드는** 순간은,
> 새 정보가 가격을 옮긴 것이 아니라 **레버리지 포지션이 강제로 닫히는 중**일 확률이 상대적으로 높다.
> 강제 매도가 끝나면 가격은 사건 이전 수준 쪽으로 되돌아간다.

OI 감소가 핵심이다. 정보에 의한 하락이면 새 포지션이 들어와 OI가 늘거나 유지된다.
OI가 줄면서 떨어지는 것은 **포지션 청산**의 그림자다. 청산 데이터가 쌓이면 직접 검증할 구조다(14절).

**C2 - 숏 스퀴즈 후 정상화 (SHORT)**
> 같은 메커니즘의 반대 방향. 15분 10시그마 급등 + OI 감소 = **숏이 강제로 닫히는 중**.
> 강제 매수가 끝나면 되돌아온다.

**SHORT를 별도 근거로 켠 이유**(§14 요구): 메커니즘이 대칭이다. 강제 청산은 방향을 가리지 않고,
OI 감소라는 관측 가능한 그림자도 같다. 기존 연구의 LONG 편향은 **버킷 수준 평균회귀**에서 관측된 것이지
**강제 청산 사건**에서 검증된 적이 없다. 다만 2021~2026 BTC 상승 drift가 SHORT에 불리하게 작용한다는
점은 결과 해석에서 명시한다.

**C3 - 변동성 충격 소진 (LONG)**
> `HIGH volatility`는 **상태**이고 `volatility shock`은 **사건**이다. D6-C는 상태를 조건으로 써서
> 실패했다(G9: HIGH가 MID보다 나쁨). 이번에는 **15분 변동성이 24시간 변동성의 4배로 팽창하면서
> 동시에 5시그마 급락**한 순간만 사건으로 본다. 팽창이 끝나면 변동성과 가격 모두 정상으로 돌아간다.

**C4 - 다중 극단 동시 발생 (LONG)**
> 급락 + OI 감소 + perp 할인이 동시에 극단일 때. 세 구조가 독립적으로 극단이라는 것은
> 단일 원인(강제 청산)이 셋을 동시에 밀었을 확률을 높인다.

**D5.2 C1과의 차이(복제 금지 준수)**: D5.2 C1은 `basis 하위 10% ∩ OI 1h 감소 ∩ 고변동성 상태`로
**버킷·상태 기반**이었고 임계값이 완전히 다르다. C4는 **15분 변위 6시그마**를 주축으로 하고
OI·basis는 보조 조건이며, 고변동성 **상태** 조건을 쓰지 않는다(D6-C G9가 그 조건을 반증했다).
D5.2 C1의 threshold를 그대로 쓴 것은 하나도 없다.

## 8. 실행 계약

### 8.1 Decision / Execution 분리 (D6 I1 원칙 재사용)

| 시점 | 내용 |
|---|---|
| **결정 `t`** (event start bar 종가 후) | `t`까지의 bar만. 방향, `target_notional`, `target_distance`, `stop_distance` 확정. **가격 불필요** |
| **실행 `t+1`** | 기준가 `open[t+1]`, `qty = floor_to_step(target_notional / open[t+1], 0.001)`. MARKET taker |
| 목표가 / 손절가 | **실제 체결가** 기준으로 계산 |

`t+1` 가격은 event 성립 여부·방향을 바꾸지 않는다. 실행 실패는 `EXECUTION_REJECT`이고
**event를 없었던 것으로 재작성하지 않는다.**

### 8.2 Exit (후보당 정확히 3개)

`D = |disp15|` (event start bar에서 관측된 변위 크기).

| # | 규칙 | 정의 |
|---|---|---|
| **X1 정상화 청산** | 목표 도달 | LONG: mark high ≥ `entry x (1 + clip(0.5 x D, 0.003, 0.05))` / SHORT: mark low ≤ `entry x (1 - ...)` |
| **X2 위험 손절** | 사건 무효화 | LONG: mark low ≤ `entry x (1 - clip(0.5 x D, 0.003, 0.05))` / SHORT: 반대 |
| **X3 최대 보유** | **240 bar (4시간)** | 도달 시 그 bar `open`에 청산 |

**목표와 손절이 사건 크기의 0.5배로 대칭이다.** 가정을 최소화한 선택이다:
"강제 매도가 자기 변위의 절반을 되돌린다"에 걸고, "절반만큼 더 밀리면 가설이 틀렸다"로 끊는다.
비대칭 비율을 고르면 그 자체가 결과 없는 튜닝이 된다.

clip 하한 0.30% / 상한 5.00%는 극단 event에서 목표·손절이 비현실적으로 넓어지는 것을 막는다.
median D가 130~170bp이므로 통상 목표·손절 거리는 **65~85bp**이고, 비용 11.25bp의 **6~7배**다.

**최대 보유 240 bar 선택 근거**(§16 준수): D5.1·D5.2·D6-A·D6-C가 모두 4시간을 **주요(primary) 등급**의
가장 긴 horizon으로 동결해 두었다. 그 등급 경계를 그대로 물려받았을 뿐 **결과를 보고 고르지 않았다.**
D6-C에서 8시간이 4시간보다 덜 나빴다는 사실은 알고 있으나, 그것을 근거로 horizon을 옮기는 것이
정확히 §Z8이 금지하는 best horizon 선택이다. 8시간은 **참고 arm**으로만 돌리고 판정에 쓰지 않는다.

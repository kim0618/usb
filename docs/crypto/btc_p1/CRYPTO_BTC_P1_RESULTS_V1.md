## 3. 결정적 진단: 변동성인가 방향인가

`direction_diagnostic_v1.json`. **사후 진단이며 게이트에 들어가지 않았다.**

같은 예측값으로 두 질문을 분리했다.

| 질문 | 방법 |
|---|---|
| 변동성 | 어느 쪽이든 터치했는가. score = `P(UP) + P(DOWN)` |

### 5.2 M0가 완전한 상수가 아니다

M0는 **fold별 train base rate**라 pooled 기준으로 9개 값을 갖는다.
그래서 pooled M0의 AUC가 0.5가 아니라 0.522~0.556이다.
Brier skill은 이 M0 대비이므로 **오히려 보수적인 비교**다.

### 5.3 untouched holdout이 아니다

2021~2026은 D5·D5.1·D5.2·D6가 이미 본 구간이다.
이 결과는 **development / historical validation**이며 true OOS가 아니다.

### 5.4 Selection bias

모델 2개 × PATH 14개 = **28회 비교**이고 target 판정은 더 좋은 모델을 쓴다.
S6·S7(fold·year 일관성)이 이를 어렵게 만들지만 없애지는 못한다.
다만 6개 STRONG이 **fold 9/9, year 5/5**로 통과한 것은 단일 우연으로 설명하기 어렵다.

### 5.5 라벨 중첩

결정 시점이 1시간 간격인데 horizon은 4~24시간이라 인접 라벨이 겹친다.
유효 독립 표본은 41,400보다 훨씬 적다. **p-value를 계산하지 않은 이유이고, 계산하지 않았다.**

## 6. 계약상 판정과 그 한계

### 6.1 규칙대로의 판정

> §14: **PATH 계열에서 STRONG_SIGNAL이 최소 하나 → BTC-P2 = AUTHORIZED**

PATH STRONG 6개. **기계적으로 BTC-P2 = AUTHORIZED.**

### 6.2 그런데 게이트가 연구 질문을 측정하지 못했다

§1의 질문은 "큰 움직임을 **어느 방향으로** 만들 확률"이었다.
게이트 S1~S7은 **방향별 target을 각각** 평가하므로,
UP과 DOWN을 똑같이 밀어올리는 변동성 모델이 양쪽 다 통과시킨다.

**이것은 결과를 보고 내린 판단이 아니라 게이트 설계의 구조적 성질이다.**
그리고 §17 R4에 따라 **게이트를 사후 수정하지 않았다.** 판정은 위 그대로 남긴다.

### 6.3 P2로 가면 무슨 일이 생기나

§33이 그린 P2는 이렇다:

```
P(DOWN >= 2%) = 62%
P(UP >= 2%) = 13%
→ SHORT
```

실측은 그런 분리를 만들지 않는다. 24H_200에서 두 확률의 차이가 가장 큰 10분위의
실제 결과는 DOWN 0.351 / UP 0.307이고, 24H_100에서는 **부호가 반대**다.
방향 AUC 0.51에 왕복 11bp를 빼면 D5.5와 같은 자리로 돌아간다.

## 3. 이것이 말하는 것

### 3.1 모델은 변동성 예측기다

F2를 치환하면 Brier가 0.03~0.05 나빠지고, 나머지 다섯을 전부 치환해도 0.005 안쪽이다.
**34개 컬럼짜리 모델이라고 불렀지만 실제로 작동한 것은 6개다.**

F6이 2위인 것도 독립적 기여로 보기 어렵다. F6의 `vol_regime_ln`은
`rv_24h / rv_24h의 30일 평균`이라 **변동성 축의 연장**이다.
순수한 시간 효과(hour·dow)는 별도로 분리하지 않았으므로,
"시간대가 정보를 준다"고 주장할 근거는 이 표에 없다.

### 3.2 D5 계열의 실패가 여기서 재확인된다

| family | D5~D5.5 결과 | BTC-P1 importance |
|---|---|---|
| F3 OI | standalone SURVIVE 0 | **0** |
| F4 basis | standalone SURVIVE 0 | **0 (대부분 음수)** |
| F5 funding | standalone SURVIVE 0 | **0 근처** |

계약 FE2는 이 셋을 "standalone alpha로 취급 금지, context feature로만"으로 묶었다.
**context로서도 값이 없었다.** 단독으로 실패한 축이 조합에서 되살아나지 않았다.

### 3.3 F1이 0인 것이 핵심 발견이다

F1은 다중 horizon 수익률 벡터·가속·range position, 즉 **방향 정보를 담을 수 있는 유일한 family**다.
그 기여가 0.001 수준이라는 것은, 모델이 방향을 못 맞히는 이유가
"방향 정보를 제대로 쓰지 못해서"가 아니라 **가격 경로에서 방향 정보를 찾지 못해서**임을 뜻한다.

이는 §3의 방향 AUC 0.502~0.533과 같은 이야기를 다른 각도에서 하고 있다.
**두 진단이 독립적으로 같은 결론에 도달했다.**

## 4. 이 진단의 한계

| # | 한계 |
|---|---|
| 1 | **마지막 fold(6,336행)만**이다. 전 구간 permutation은 하지 않았다 |
| 2 | family 단위라 family 안에서 어느 컬럼이 일했는지는 모른다 |
| 3 | family끼리 상관이 있으면 permutation importance는 기여를 과소평가한다. F1과 F2는 둘 다 가격에서 나오므로 F1의 0이 "완전한 무정보"를 증명하지는 않는다 |
| 4 | 치환을 행 역순으로 했다. 결정적이지만 무작위 셔플과 완전히 같지는 않다 |
| 5 | **importance를 보고 feature를 바꾸지 않았다.** 바꿨다면 그 결과는 더 이상 사전등록이 아니다 |

3번 때문에 "가격 경로에 방향 정보가 전혀 없다"고 단정하지 않는다.
말할 수 있는 것은 **이 feature set과 이 모델에서는 찾지 못했다**는 것이다.

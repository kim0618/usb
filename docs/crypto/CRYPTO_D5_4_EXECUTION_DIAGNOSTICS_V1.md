## 3. 합성 호가의 영향

**과거 호가는 존재하지 않는다**(D1). 체결가는 **모델 출력이며 실제 과거 슬리피지가 아니다.**

| 항목 | 값 |
|---|---|
| spread 가정 | 0.10 USDT (1 tick) |
| 깊이 가정 | 5 BTC / 측, 평탄 |
| 최대 주문 | 0.40 ~ 0.44 BTC |
| **최대 주문 / 깊이** | **8.0 ~ 8.8%** |

D6-C(1.4%)보다 크다. 이유는 이 전략의 명목이 크기 때문이다: 브래킷이 좁은 사건에서
`equity x 0.005 / stop_distance`가 자본에 근접한다.

### 체결가 슬리피지 (중앙값)

| 후보 | 손절: 의도 → 실현 | 목표: 의도 → 실현 |
|---|---|---|
| C1 | -87 → -87bp (0.0) | +85 → +85bp (0.0) |
| C2 | -81 → -81bp (0.0) | +83 → +83bp (0.0) |
| C3 | -66 → -66bp (0.0) | +64 → +64bp (0.0) |
| C4 | -70 → -70bp (-0.5) | +68 → +68bp (0.0) |

**중앙값 기준 갭 통과는 거의 없었다.** 브래킷이 65~87bp로 넓어 1분 bar가 그것을 건너뛰는 일이 드물다.

다만 **꼬리에서는 다르다**: 최악 거래가 -224 ~ -262bp로 손절 폭의 **3배 이상**이다.
이것은 갭으로 손절을 크게 통과한 사건이며, 희귀사건 전략의 실제 꼬리 위험이다.
중앙값만 보면 놓친다.

## 5. 명목 상한과 엔진 거부

| 후보 | 명목 상한(1.0x 자본) 구속 | 엔진 거부 |
|---|---|---|
| C1 | 18 / 252 (7.1%) | 2 |
| C2 | 17 / 229 (7.4%) | 4 |
| C3 | **46 / 201 (22.9%)** | 6 |
| C4 | **43 / 212 (20.3%)** | 7 |

**D6-C에서는 상한 구속이 0건이었다.** 이번에 구속되는 이유는 브래킷이 사건 크기에 비례하는데,
clip 하한(0.30%)에 가까운 좁은 브래킷에서 `0.005 / 0.003 = 1.67배`가 되어 상한에 걸리기 때문이다.
계약 9절이 "상한이 실제로 구속되는 후보가 있다는 점을 보고한다"고 예고한 그대로다.

### 엔진 거부 19건의 정체

```
requires 7674.15 but available balance is 7670.92
```

1x 레버리지에서 명목 = 자본이면 **초기 증거금이 자본 전액**이라 수수료 낼 현금이 남지 않는다.
계약대로 `EXECUTION_REJECT_ENGINE`으로 기록했고 **거래로 세지 않았다.**
신호 품질(이벤트 발생)과 실행 실패를 분리해 보고한다는 계약 30절 요구를 지켰다.

이것은 결함이 아니라 **계약이 정한 상한의 논리적 귀결**이다. 19건은 894건의 2.1%이고,
전부 명목 상한에 걸린 좁은 브래킷 사건이라 결론에 영향을 주지 않는다.

## 6. 보유 시간과 청산 구성

| 후보 | 평균 보유 | 손절 median 보유 | 목표 median 보유 | 시간만료 |
|---|---|---|---|---|
| C1 | 51분 | 14분 | 16분 | 18 / 252 (7.1%) |
| C2 | 54분 | 18분 | 22분 | 21 / 229 (9.2%) |
| C3 | 32분 | 5분 | 7분 | 10 / 201 (5.0%) |
| C4 | 35분 | 10분 | 10분 | 9 / 212 (4.2%) |

**브래킷이 거의 항상 먼저 닿는다.** 최대 보유 240분에 도달한 거래는 4~9%뿐이고,
중앙 보유는 5~22분이다.

이것이 중요한 이유: **최대 보유 240분 선택이 결과를 좌우하지 않았다.**
계약 8.2절이 horizon을 D5.1·D6에서 물려받았다고 적었는데, 실제로 95% 이상의 거래가
그 한참 전에 브래킷으로 끝났다. REF-8H arm이 BASE와 거의 같은 결과를 낸 것도 같은 이유다
(C1 -5.36 vs -4.92, C3 -4.44 vs -3.79).

**horizon 선택은 이번 결과에서 사실상 무관한 변수였다.**

## 8. 이 진단이 뒷받침하는 것과 하지 못하는 것

### 뒷받침하는 것
1. 회계는 정확하다(항등식 894/894).
2. 이벤트 정의는 계약과 일치한다(4/4 후보 정확 일치).
3. 병합이 표본 부풀림을 실제로 제거했다(7배 압축).
4. intrabar 가정과 horizon 선택은 결론을 좌우하지 않았다.
5. 중앙값 기준 체결 슬리피지는 0에 가깝다.

### 뒷받침하지 못하는 것
1. **합성 호가는 실제 호가가 아니다.** 주문/깊이 8~9%에서 실제 시장 충격이 어땠을지 모른다.
   특히 이 전략은 **유동성이 가장 나쁜 순간**(10시그마 급변)에 진입하므로,
   실제 슬리피지는 모델보다 나빴을 가능성이 높고 **방향은 결과를 더 나쁘게 만드는 쪽이다.**
2. 꼬리 체결(-262bp 같은 건)의 실제 체결 가능성은 검증할 수 없다.
3. 2021~2026은 이미 여러 번 본 구간이다. historical confirmation evidence다.

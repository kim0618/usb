## 7. 집중도 - 수익이 어디서 왔는가

총 net이 음수라 기여도 비율은 의미가 없다(`NOT_MEANINGFUL`). 절대값으로 본다.

| 항목 | 값 |
|---|---|
| 총 net | **-413.86** |
| 최고 1건 | +330.75 |
| 상위 2건 합 | +340.47 |
| 상위 3건 합 | +345.88 |
| 상위 5건 합 | +347.13 |
| **상위 1건 제외 후 net** | **-744.61** |
| **상위 3건 제외 후 net** | **-759.74** |
| 최악 1건 | -600.56 |
| **최악 1건 제외 후 net** | **+186.70** |

두 가지를 동시에 읽어야 한다.

1. **이익은 극단적으로 집중돼 있다.** 상위 1건이 전체 이익의 대부분이고, 빼면 -744.61이다.
2. **손실도 극단적으로 집중돼 있다.** 청산 1건을 빼면 +186.70으로 플러스가 된다.

**"청산만 없었으면 벌었다"는 사실이지만 전략 평가가 아니다.** 청산은 레버리지 선택의 결과이지
제거 가능한 사고가 아니다. 거꾸로 "최고 1건만 없었어도 크게 잃었다"도 똑같이 사실이다.
**17건 중 2건이 나머지 15건 전체보다 크다.**

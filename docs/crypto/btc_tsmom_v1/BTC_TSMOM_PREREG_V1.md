# BTC 일봉 시계열 모멘텀(추세추종) 사전등록 V1

| 항목 | 내용 |
|---|---|
| 상태 | **FROZEN (2026-11-02), 수익률 계산 전.** SHA256은 결과 문서에 기록 |
| 작성 | 2026-11-02, Claude Code Opus 5.5(claude-opus-5-5). 근거: 사용자 "한번 해보자"(비트코인 롱·숏 방향을 며칠~몇 주 단위로) |
| 왜 새 질문인가 | 지금까지 BTC 방향 연구(D5 1분, Direction R0 15분~24시간, P1/P2 4시간)는 전부 하루 이내였다. 며칠~몇 주 추세추종은 처음이다 |
| 자료 | Binance USDⓈ-M BTCUSDT 무기한 일봉(00:00 UTC 기준)과 펀딩비 전체 이력, 공개 REST(fapi/v1/klines, fapi/v1/fundingRate). 상장 2019-09 ~ 2026-11-01 |

## 규칙

- 신호(일 t 종가 기준): 과거 N일 수익률 R = C(t) / C(t−N) − 1. N ∈ {7, 14, 28, 56}. 네 개 모두 보고하고, 판정은 아래 "주 변형"으로 한다.
- 포지션(일 t+1 시가 = t 종가로 체결, 다음 날 보유):
  - **LS(롱·숏)**: R > 0이면 롱 1배, R ≤ 0이면 숏 1배.
  - **LF(롱·현금)**: R > 0이면 롱 1배, 아니면 현금(수익 0).
- 레버리지 1배 고정. 복리, 매일 재조정 없음(포지션 방향이 바뀔 때만 거래).
- 비용: 방향 전환 때 편도 0.05% × 거래 횟수(LS 전환은 청산+진입 = 0.10%). 펀딩비: 보유 중 8시간마다 실제 펀딩비를 롱은 지불(양수일 때), 숏은 수취.
- 비교 기준: **BH**(첫날부터 롱 1배 계속 보유, 펀딩 반영).
- 구간: 신호 이력 56일 확보 뒤 시작. **탐색 A = 2019-11-05 ~ 2022-12-31, 검증 B = 2023-01-01 ~ 2026-10-31.** 구간마다 독립 계산(B 시작 시점 원금 1로 리셋).
- 지표: 연환산 수익(CAGR), 연환산 변동성, 샤프(무위험 0), 일별 MDD, 연도별 수익, 연간 거래 횟수, 시장 노출 비율.

## 판정 (결과 전 고정)

- **주 변형 = N 28, LF.** (학계 보고의 중심 구간 1~4주, 롱·현금이 BTC 장기 상승 특성에 맞음.)
- **PASS**: 주 변형이 A와 B **둘 다**에서 BH보다 샤프가 높고 MDD가 작다.
- **PARTIAL**: 주 변형이 둘 중 한 구간에서만 PASS 조건을 만족하거나, 샤프만 높고 MDD 조건 실패.
- **FAIL**: 주 변형이 두 구간 모두에서 BH보다 샤프가 낮다.
- 나머지 7개 변형(N 7·14·56, LS 4개)은 묘사다. 결과를 보고 주 변형을 바꾸지 않는다. "가장 좋은 N"을 고르는 것은 이 문서의 판정 범위가 아니다.
- PASS여도 실계좌 운용은 별도 결정이다. 레버리지는 1배를 넘기지 않는다는 조건을 붙인다.

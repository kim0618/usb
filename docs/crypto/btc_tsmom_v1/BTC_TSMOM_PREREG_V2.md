## 1부. 롱·현금(LF) 견고성

- 격자: 기준 시각 h ∈ {00, 04, 08, 12, 16, 20 UTC} × N ∈ {20, 24, 28, 32, 36, 40} = 36조합, 구간 A·B 각각.
- **ROBUST**: A·B 각각에서 (1) 36조합 중 80% 이상(29개 이상)이 BH보다 샤프 높고, (2) 36조합 샤프 중앙값 > BH 샤프.
- **FRAGILE**: 위 조건을 한 구간이라도 못 넘음. 이 경우 V1 PASS는 기준 시각·N 선택 운으로 본다.

## 2부. 3단계(롱·현금·숏) 후보 (기준 시각 00 UTC, R28 = 28일 수익률)

| 후보 | 롱 | 숏 | 그 외 |
|---|---|---|---|
| S1 이중 확인 | R28 > 0 | R28 < 0 이고 R56 < 0 | 현금 |
| S2 깊은 하락 | R28 > 0 | R28 < −10% | 현금 |
| S3 장기 추세 아래 | R28 > 0 | R28 ≤ 0 이고 종가 < 200일 단순평균 | 현금 |

- 비교 대상은 V1 주 변형 LF28(같은 기준 시각 00).
- **ADOPT_CANDIDATE**: 후보가 A·B **둘 다**에서 LF28보다 샤프 높음. 여러 개면 전부 보고하고 하나를 고르지 않는다(고르는 건 V3 사전등록).
- 그 외 → 숏은 넣지 않는다(LF 유지).
- 묘사: 통과 후보가 있으면 1부와 같은 기준 시각 6개에서도 LF보다 나은지 표시.

결과 뒤 격자·후보·기준을 바꾸지 않는다.

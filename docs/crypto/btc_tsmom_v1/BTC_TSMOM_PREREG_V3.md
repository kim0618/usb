# BTC 시계열 모멘텀 사전등록 V3 (36조합 앙상블 롱·현금)

| 항목 | 내용 |
|---|---|
| 상태 | **FROZEN (2026-11-02), V3 계산 전.** V1(LF28 PASS)·V2(견고성 FRAGILE, 숏 미채택)를 본 뒤 작성. SHA256은 결과 문서에 기록 |
| 작성 | 2026-11-02, Claude Code Opus 5.5. 근거: 사용자 "진행해봐" |
| 목적 | 특정 N·기준시각 하나의 운을 없앤 형태로 롱·현금 규칙이 두 구간 모두에서 성립하는지. 목적은 "BTC 롱의 낙폭 보험 + 위험 대비 수익" |
| 자료 | V2와 같음(4시간봉 15,670개, 펀딩비 7,830건) |

## 규칙

- 하위 전략 36개 = 기준 시각 h ∈ {00, 04, 08, 12, 16, 20 UTC} × N ∈ {20, 24, 28, 32, 36, 40}. 각 하위 전략은 V2 1부와 같다: 매일 h시 종가에서 N일 수익률 > 0이면 롱 1, 아니면 0. 다음 날 h시까지 유지.
- 앙상블 비중 w(t) = 36개 하위 전략 포지션의 평균(0 ~ 1). 4시간봉마다 갱신(하위 전략은 하루 한 번만 바뀌므로 w는 4시간마다 최대 6개 하위 전략분 변함).
- 수익: 4시간봉마다 w × 봉 수익률 − w × (그 봉 안의 펀딩비 합) − 0.05% × |w 변화량|.
- 숏 없음, 레버리지 1배 초과 없음.
- 비교: BH(선물 롱 1 계속 보유, 같은 4시간봉·펀딩). 묘사: V1 LF28(00h), 현물 기준(펀딩 0) 앙상블·BH.
- 구간 A 2019-11-05 ~ 2022-12-31, B 2023-01-01 ~ 2026-10-31(UTC 날짜, 구간마다 원금 1로 시작).
- 지표: 연환산 수익(CAGR), 샤프(4시간 수익 × √2190), MDD(4시간 기준), 평균 비중, 연간 회전(∑|Δw|).

## 판정 (결과 전 고정)

- **PASS**: A·B 각각에서 앙상블 샤프 > BH 샤프 **그리고** 앙상블 MDD가 BH MDD보다 작음.
- **PARTIAL**: 두 구간 모두 MDD는 작지만 샤프 조건을 한 구간에서 실패.
- **FAIL**: 그 외.
- PASS면 다음 단계는 현물 기준 소액 forward 운용 계획(별도 문서, 사용자 결정). 결과 뒤 하위 전략 집합·비용·구간을 바꾸지 않는다.

# BTC 추세 사전등록 V4 (빠른 롱 앙상블 + 하락장 숏, 하락장 3회 자료)

| 항목 | 내용 |
|---|---|
| 상태 | **FROZEN (2026-11-02), V4 계산 전.** V1~V3, 2022 월별 분해, "36개 전부 하락 뒤 7일 +0.5%" 탐색을 본 뒤 작성. SHA256은 결과 문서에 기록 |
| 작성 | 2026-11-02, Claude Code Opus 5.5. 근거: 사용자 "현금 대신 숏", "단위가 너무 길다", "진행해봐" |
| 자료 | 가격 = Bitstamp BTCUSD 일봉(00:00 UTC, 공개 API, 2011~). 펀딩 = 2019-09-10 이전 0, 이후 Binance BTCUSDT 실제값(V1 funding.json, 일 합계). 하루 단위라 기준 시각은 00 UTC 하나 |
| 비용 | 포지션 변화량 × 0.05%. 롱은 펀딩 지불, 숏은 펀딩 수취(음수면 반대) |

## 롱 쪽 (비중 w, 0 ~ 1)

- SLOW: N ∈ {20, 24, 28, 32, 36, 40}일 수익률 > 0인 비율.
- FAST: N ∈ {10, 12, 14, 16, 18, 20}일 수익률 > 0인 비율.
- 결정은 일 t 종가, 적용은 t+1일.

## 롱 아닐 때 (남는 1 − w)

- CASH: 0.
- 공통 하락장 정의 BEAR(t) = 종가 < 200일 단순평균(SMA200).
- **R1 반등 실패**: BEAR 이고 SMA50(t) < SMA50(t−10) 이고 종가(t−1) > SMA20(t−1) 이고 종가(t) < SMA20(t) 이면 숏 시작. 종가 > SMA20 이거나 BEAR가 아니게 되면 숏 종료.
- **R2 반등 과열**: BEAR 이고 7일 수익률 ≥ +10% 이면 그다음 7일 숏(보유 중 재발생하면 7일 연장).
- **R3 느린 하락장**: 종가 < SMA200 이고 SMA200이 직전 30일 연속 하락이면 숏 유지.
- 숏 비중 = −(1 − w) (롱에 쓰지 않은 몫만 숏, 총 노출 1배 이하).

## 구간

- 하락장: **BEAR14** 2014-01-01 ~ 2015-12-31, **BEAR18** 2018-01-01 ~ 2018-12-31, **BEAR22** 2022-01-01 ~ 2022-12-31.
- 상승·혼합: **B** 2023-01-01 ~ 2026-10-31. 참고(묘사): 2016-01-01 ~ 2017-12-31, 2019-01-01 ~ 2021-12-31.
- 전체: 2013-01-01 ~ 2026-10-31. 구간마다 원금 1로 시작.

## 판정 (결과 전 고정)

1. **롱 속도**: FAST가 SLOW보다 샤프가 2013-01-01 ~ 2018-12-31 과 2019-01-01 ~ 2026-10-31 **둘 다**에서 높으면 FAST_PREFERRED, 아니면 SLOW 유지.
2. **숏 채택**: (1)에서 정한 롱 쪽 기준으로, 숏 후보 R가
   - BEAR14·BEAR18·BEAR22 **세 구간 모두**에서 CASH 버전보다 누적 수익이 높고,
   - B 구간 샤프가 CASH 버전보다 0.10 넘게 낮지 않으면 **SHORT_ADOPT_CANDIDATE**.
   - 여러 개 통과하면 전부 보고, 하나를 고르는 것은 V5.
3. 통과 후보가 없으면 "추세·이동평균 계열 숏 규칙 근거 없음, 롱·현금 유지"로 이 방향을 닫는다.
4. 묘사: 6개 조합(SLOW/FAST × CASH/R1/R2/R3 중 판정 대상) 전체의 구간별 샤프·누적·MDD.

# US-B CRYPTO 연구 구간 V1 (확정)

작성 2026-09-23. **이 문서는 계약이다.** D0의 U2와 D2 H.1에서 후보로만 남겨 두었던 연구 구간을
사용자 결정으로 확정한다. 이 값을 바꾸려면 새 버전 문서를 만든다.

---

## 1. 확정 사항

| # | 항목 | 값 |
|---|---|---|
| W1 | **Research Window V1 시작** | **2021-02-01T00:00:00Z (이상)** |
| W2 | 끝 | 열려 있다. 데이터가 있는 최신 시점까지 |
| W3 | 2020-03 ~ 2021-01 raw 데이터 | **보존한다. 연구에서만 제외한다** |
| W4 | 결정 주체 | 사용자 (D3 지시) |
| W5 | 근거 | D2 월별 품질 전수 리포트의 엄격 규칙 후보 |

W1은 D2가 기계적으로 산출한 두 후보 중 **엄격 규칙**(zero-volume이 정확히 0인 최초의 완전한 달)을
채택한 것이다. 느슨한 후보였던 2021-01은 채택되지 않았다.

## 2. 근거 수치

`data/runtime/crypto/BTCUSDT/quality/kline_1m_monthly.json` (79개월 전수)

| 구간 | 개월 | 1m bar | zero-volume | 비율 |
|---|---|---|---|---|
| 제외 (2020-03 ~ 2021-01) | 11 | 450,084 | 28,529 | **6.3386%** |
| 포함 (2021-02 ~ 2026-09) | 68 | 2,966,494 | 68 | **0.002292%** |

포함 구간의 missing 0, duplicate 0, invalid OHLC 0이다. 제외 구간도 결손·중복·OHLC 위반은 0이며,
**유일한 차이는 zero-volume 비율이다.** 2020-10은 16.5%까지 올라간다.

제외 구간을 버리는 대가는 전체 표본의 13.2%(450,084 / 3,416,578 bar)다. 그 대가로 거래가 실제로
있었던 bar만 남는다.

## 3. 이 계약이 강제하는 것

| # | 규칙 |
|---|---|
| R1 | 연구·백테스트·파라미터 탐색은 **2021-02-01T00:00:00Z 이상**만 입력으로 받는다 |
| R2 | 2021-02 이전 raw 파일은 **삭제하지 않는다.** `historical/`에 그대로 둔다 |
| R3 | 제외 구간을 쓰는 분석은 그 사실과 이유를 결과에 **명시 기록**한다. 조용히 쓰지 않는다 |
| R4 | 연구 산출물은 사용한 창의 시작·끝을 기록한다. "전체 이력"이라는 표현을 쓰지 않는다 |
| R5 | OI 공통 시작점(2020-08-04)은 W1보다 이르므로 **추가 제약이 되지 않는다** |

## 4. 다른 시계열과의 관계

| 데이터 | 실제 시작 | W1과의 관계 |
|---|---|---|
| `kline_1m` | 2020-03-25T10:36:00Z | W1이 더 늦다 |
| `funding` | 2020-03-25T16:00:00Z | W1이 더 늦다 |
| `open_interest_5m` | 2020-08-04T07:50:00Z | W1이 더 늦다 |
| `mark_1m` | 2020-03-25T08:41:00Z | W1이 더 늦다 |
| `index_1m` | 2020-03-25T07:57:00Z | W1이 더 늦다 |

**다섯 시계열 전부 W1 이전에 시작한다.** 따라서 2021-02-01부터는 다섯 시계열이 모두 존재하며,
연구 창의 시작을 결정하는 것은 데이터 가용성이 아니라 **품질 기준**이다.

D2가 계산한 공통 overlap window는 2020-08-04T07:50:00Z ~ 2026-09-23T00:00:00Z였다. W1은 그 안에
있고, 끝(funding 정산 주기가 결정)은 그대로 유효하다.

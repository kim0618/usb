## 0. D5.4가 남긴 질문

D5.4는 극단 사건 직후 **즉시 방향을 골랐고** 실패했다.

| 후보 | 거래 | gross | net | 목표 적중률 |
|---|---|---|---|---|
| C1 E1-LONG | 252 | +6.22bp | -4.92bp | 0.521 |
| C2 E1-SHORT | 229 | -0.33bp | -11.29bp | **0.500** |
| C3 E3-LONG | 201 | +7.30bp | -3.79bp | 0.545 |
| C4 E4 | 212 | +1.81bp | -9.26bp | 0.502 |

사건 변위는 130~171bp로 왕복 비용(11.25bp)의 **12~15배**였다. 움직임이 모자란 것도, 수수료만 비싼 것도
아니었다. **C2는 손절 104건 대 목표 104건이었다.**

> **극단 사건 발생 시점에는 이후 방향 정보가 없었다.**

그래서 이번에는 사건을 **방향 예측기가 아니라 거래 기회 활성화 신호**로만 쓴다.

```
IDLE → EVENT_ACTIVE → WAIT_CONFIRMATION → CONFIRMED_LONG / CONFIRMED_SHORT → POSITION → COOLDOWN
                            ↓ (확인 없음)
                         EXPIRED → COOLDOWN
```

**연구 질문**: 큰 사건 이후 **시장이 실제로 방향을 보여준 뒤** 들어가면, 너무 늦지 않으면서도
잘못된 방향을 충분히 걸러내 VIP0 비용 후 edge가 생기는가?

## 2. 사건 원천 (D5.4 detector 재사용, threshold 무변경)

**새 사건 threshold를 탐색하지 않는다.** D5.4가 이미 동결한 E1 detector를 그대로 쓰되,
이번 연구에서 사건은 방향을 갖지 않으므로 **양방향으로 합집합**한다.

```
SHOCK = |z(disp15)| >= 10.0   AND   z(oichg15) <= -2.5
```

| 항목 | 값 |
|---|---|
| D5.4 C1 (LONG측) | `z(disp15) <= -10.0 & z(oichg15) <= -2.5` |
| D5.4 C2 (SHORT측) | `z(disp15) >= +10.0 & z(oichg15) <= -2.5` |
| **D5.5 SHOCK** | **위 둘의 합집합. 숫자 변경 0** |

`disp15`, `oichg15`, robust z(30일 median/MAD), 병합 규칙, 쿨다운 240 bar는 **D5.4 계약 그대로**이며
코드도 `app.crypto.research.d5_4.events`를 재사용한다.

| 항목 | 값 |
|---|---|
| OOS 사건 | **415** (2022-01-01 ~ 2026-09-23) |
| 연도별 | 2022: 94 / 2023: 157 / 2024: 53 / 2025: 58 / 2026: 53 |
| 방향 | 급등 199 / 급락 216 |
| 지속 | median 3 bar, p90 9 bar |

### 쓰지 않는 family와 이유

| family | 처리 |
|---|---|
| D5.4 E2 (basis 괴리) | **재도입 금지.** cost-first 단계에서 이미 탈락(괴리 자체가 비용의 0.63~2.57배) |
| D5.4 E3 (변동성 충격) | **이번에 쓰지 않는다.** 아래 참조 |
| D5.4 E4 (다중 극단) | **이번에 쓰지 않는다.** 아래 참조 |

**사건 원천을 하나로 고정한 이유**: 이번 연구의 변수는 **확인 논리**다. 후보마다 다른 사건을 쓰면
"확인이 도움이 되는가"와 "어떤 사건이 나은가"가 섞여 답을 분리할 수 없다. 세 후보가 **같은 415개 사건**을
공유하므로 차이는 전부 확인 방식에서 온다. E3·E4는 E1의 부분집합이거나 변동성 조건이 겹쳐
독립 비교가 되지 않는다.

## 3. Shock window와 range (동결)

사건의 크기는 **변위를 만든 창 전체**로 잰다. 사건 bar(median 3개)만 보면 range가 54bp로
변위(170bp)의 1/3밖에 안 되고, 그 위에 세운 margin은 비용의 1.2배에 불과해 필터가 되지 못한다
(사전 QC에서 확인).

```
shock window = [event.start - 14, event.end]        # disp15를 만든 15 bar + 사건 지속분
H  = max(mark_high[shock window])
L  = min(mark_low[shock window])
P0 = close[event.start - 14]                        # 충격 이전 가격
R  = (H - L) / ((H + L) / 2)                        # range 폭 (비율)
```

| 항목 | 값 |
|---|---|
| R 분포 | p25 165bp / **median 218bp** / p75 303bp |

## 4. 확인 후보 3개 (동결)

세 후보 모두 **같은 415개 사건**에서 출발하고, **확인 window는 60분**이다.

### 4.0 공통 규칙

| # | 규칙 |
|---|---|
| K1 | **확인 window = 사건 종료 후 60 bar.** 사건 창(15분)의 4배. 단일 값, 탐색 0 |
| K2 | window 안에 확인이 없으면 **`NO_TRADE`**. 억지 진입 금지 |
| K3 | **사건당 최대 1거래.** LONG 확인 뒤 SHORT 확인이 나와도 reverse 금지 |
| K4 | 확인 판정은 **종가**로 한다(`close[i]`). intrabar 터치는 확인이 아니다 |
| K5 | **모든 확인 margin의 하한은 `2 x 왕복비용 = 22.5bp`**다. 그보다 좁은 구조 돌파는 노이즈와 구분되지 않는다 |
| K6 | 확인 시점 `t` → 진입은 `open[t+1]` (D6 I1) |

### 4.1 Candidate A - SHOCK_BREAKOUT_CONTINUATION (LONG·SHORT)

```
margin m = max(0.25 * R, 22.5bp)
UP   확인: close > H * (1 + m)   ->  LONG
DOWN 확인: close < L * (1 - m)   ->  SHORT
먼저 성립한 쪽이 이긴다
```

**가설**: 충격이 만든 range를 의미 있는 폭으로 벗어난다는 것은 충격을 만든 흐름이 아직 끝나지 않았다는
신호다. 방향은 사건이 아니라 **돌파가** 알려준다.

| 항목 | 값 |
|---|---|
| 확인율 | **33.0%** (137 / 415) |
| LONG / SHORT / NO_TRADE | 70 / 67 / 278 |
| 확인까지 median | 22분 |
| 확인 거리 median | 59.2bp |
| margin median | 54.5bp (**비용의 4.8배**) |

**k = 0.25 선택 근거**(사전 고정 사다리 {0.15, 0.25, 0.40}): k=0.15에서는 사건의 **17.1%**가
비용 하한(22.5bp)에 걸려 range 비례 규칙이 더 이상 구속 규칙이 아니게 된다. k=0.25에서 그 비율이
**0.5%**로 떨어진다. **설계의 내적 정합성이 기준이며 수익률을 보지 않았다.**

**Exit**: 손절 = **돌파된 레벨 자체**(LONG은 H, SHORT는 L). 되돌아오면 돌파 실패다.
목표 없음. 최대 보유 240 bar.

### 4.2 Candidate B - SHOCK_RETRACEMENT_CONFIRMATION (LONG·SHORT)

```
급락 사건: level = L + 0.5 * (P0 - L)   (충격의 절반 되돌림)
           close > level  ->  LONG,  손절 = L
급등 사건: level = H - 0.5 * (H - P0)
           close < level  ->  SHORT,  손절 = H
목표 = P0 (충격 이전 가격, 정상화 완료)
```

**가설**: 충격이 절반 되돌려졌다는 것은 강제 흐름이 끝나고 정상화가 **실제로 진행 중**이라는 뜻이다.
D5.4는 충격 극값에서 바로 들어갔고, 여기서는 **절반이 되돌아온 것을 보고** 들어간다.

| 항목 | 값 |
|---|---|
| 확인율 | **53.0%** (220 / 415) |
| LONG / SHORT / NO_TRADE | 115 / 105 / 195 |
| 확인까지 median | 10분 |
| 확인 거리 median | 99.3bp |

**k = 0.5 선택 근거**: 절반 되돌림은 사전적으로 표준적인 구조 레벨이고, 사다리 {0.382, 0.5, 0.618}의
**중간값**이다. 양 끝을 고르지 않았다.

**사전 QC에서 폐기한 정의**: 최초에 "직전 저점 대비 k만큼 반등"으로 정의했더니 확인율이 **99.0%**였다.
저점이 계속 갱신되므로 어떤 반등이든 결국 성립해 필터가 되지 못했다. 충격 이전 가격 `P0` 기준
되돌림으로 바꿔 53.0%가 됐다. **이 교체는 확인 빈도만 보고 했으며 수익률을 보지 않았다.**

**Exit**: 손절 = 충격 극값(L 또는 H). 새 극값을 만들면 정상화 가설이 틀렸다.
목표 = `P0`. 최대 보유 240 bar.
**사전 구조 필터**: 진입 시점에 `|P0 - entry| / entry < 22.5bp`이면 남은 공간이 비용에 못 미치므로
`NO_TRADE`로 처리한다(§26).

### 4.3 Candidate C - POST_SHOCK_COMPRESSION_EXPANSION (LONG·SHORT)

```
1단계 압축: rv15[i] < 0.5 * rv15[event.start]  인 최초 bar i
2단계 압축 range: CH = max(mark_high[i-14..i]), CL = min(mark_low[i-14..i])
3단계 확장: close > CH * (1 + 22.5bp)  ->  LONG
            close < CL * (1 - 22.5bp)  ->  SHORT
세 단계가 모두 60분 window 안에서 일어나야 한다
```

**가설**: 충격 → 소화 → 해소. 변동성이 절반으로 수축한 뒤의 돌파는 시장이 방향을 정했다는 신호다.

| 항목 | 값 |
|---|---|
| 확인율 | **43.9%** (182 / 415) |
| LONG / SHORT / NO_TRADE | 93 / 89 / 233 |
| 확인까지 median | 32분 |
| 확인 거리 median | 29.5bp |

**압축 기준 0.5 선택 근거**: "변동성이 절반으로 줄었다"는 평서문이고, 탐색하지 않았다.

**Exit**: 손절 = 압축 range의 반대편(LONG은 CL, SHORT는 CH). 목표 없음. 최대 보유 240 bar.

## 6. 실행 계약

### 6.1 Decision / Execution 분리 (D6 I1)

| 시점 | 내용 |
|---|---|
| 확인 `t` (종가) | 방향, `target_notional`, `stop_distance` 확정. **가격 불필요** |
| 실행 `t+1` | 기준가 `open[t+1]`, `qty = floor_to_step(target_notional / open[t+1], 0.001)`, MARKET taker |
| 손절가·목표가 | **실제 체결가 기준으로 재계산** |

`t+1` 가격은 확인을 소급 변경하지 않는다. 실행 실패는 `EXECUTION_REJECT`이고 확인은 남는다.

### 6.2 Exit 구조 (D5.4의 대칭 브래킷을 재사용하지 않는다)

D5.4의 대칭 브래킷이 동전 던지기였으므로 **자동 재사용하지 않는다.**
세 후보 모두 **구조적 손절 + 최대 보유**이고, B만 구조적 목표를 갖는다.

| 후보 | 손절 | 목표 | 최대 보유 |
|---|---|---|---|
| A | 돌파된 레벨 (H 또는 L) | **없음** | 240 bar |
| B | 충격 극값 (L 또는 H) | `P0` | 240 bar |
| C | 압축 range 반대편 | **없음** | 240 bar |

A·C는 **목표가 없다**. 돌파 지속 가설은 상단이 열려 있어야 성립한다.
손절 거리가 `stop_distance`이고 사이징의 분모다.

**손절 거리 clip**: `[0.003, 0.05]` (D5.4와 같은 하한·상한). 구조 레벨이 비정상적으로 가깝거나
먼 경우를 막는다.

### 6.3 Intrabar 모호성 (보수적, 동결)

| 상황 | 규칙 |
|---|---|
| 같은 bar에서 손절과 목표가 모두 닿음 | **손절이 이긴다** (adverse-first) |
| 손절 체결가 | LONG `min(stop, bar open)` / SHORT `max(stop, bar open)` |
| 목표 체결가 | LONG `max(target, bar open)` / SHORT `min(target, bar open)` |
| 트리거 기준 | mark bar 저가/고가 |
| best-case 선택 | **금지** |

## 10. 판정 기준 (결과 보기 전 동결)

### 표본 게이트 (먼저 적용)

| 항목 | 최소 |
|---|---|
| 독립 사건 | 200 |
| **확인된 거래** | **60** |
| 연도 | **5개 전부** |
| 판정 가능 fold | **5** (fold당 거래 ≥ 5) |

확인된 거래 < 60이면 **`INCONCLUSIVE`**이고 PASS가 아니다.

### SURVIVE (전부 충족)

| id | 조건 |
|---|---|
| S1 | OOS VIP0_BASE net 평균 > 0 **이고** 95% CI 하한 > 0 |
| S2 | **edge / cost ratio ≥ 2.0** |
| S3 | 위 표본 게이트 전부 충족 |
| S4 | 판정 가능 fold 중 gross > 0 ≥ 2/3, net > 0 ≥ 1/2 |
| S5 | leave-one-year-out net > 0 (전 연도) |
| S6 | 단일 거래가 총 net 합의 **20%** 이하 |
| S7 | **PF > 1.3** 이고 **MDD < 20%** |
| S8 | VIP0_STRESS net > 0 |
| S9 | 민감도 arm 전부 net > 0 |
| **S10** | **손절 청산 비율 < 50%** |

**S10이 이번 연구의 핵심 게이트다.** D5.4의 발견은 "사건 시점에 방향 정보가 없다"였다.
확인이 그것을 고쳤다면 손절로 끝나는 거래가 절반 미만이어야 한다.
이것은 whipsaw(거짓 돌파)를 직접 재는 조건이다.

### 그 외

| 판정 | 조건 |
|---|---|
| **WEAK** | S1 통과, 나머지 중 하나 이상 실패 |
| **REJECT** | S1 실패 |
| **INCONCLUSIVE** | 확인된 거래 < 60 |

기여도 비율은 총 net ≤ 0이면 `NOT_MEANINGFUL`이고 **PASS로 세지 않는다**.

## 16. 사전 예상 (결과 보기 전 기록)

| 항목 | 예상 |
|---|---|
| 판정 | **SURVIVE 0 쪽에 무게를 둔다.** 다섯 번 연속 실패한 시장이고, 확인 대기는 방법론 개선이지 새 정보원이 아니다 |
| 가장 먼저 깨질 조건 | **S10(손절 비율)**. 확인이 방향 정보를 만들지 못하면 손절 비율이 50% 근처로 나온다 |
| 이번 실험이 새로 답하는 것 | D5.4는 "사건 시점에 방향 정보가 없다"를 보였다. 이번은 **"사건 이후 가격 행동에는 방향 정보가 있는가"**를 묻는다. 두 답은 독립이고, 둘 다 없다면 이 시장의 단기 방향성 자체에 대한 결론이 된다 |
| 구조적 차이 | A·C는 **목표가 없다**. D5.4의 대칭 브래킷과 달리 상단이 열려 있어, 실패한다면 "추세가 이어지지 않는다"가 원인이고 이는 새 정보다 |

이 예상은 결과를 보기 전에 적었고, 결과에 맞춰 수정하지 않는다.

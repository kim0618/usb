## 1. C1 - E1 EXTREME_DELEVERAGING (LONG)

### 정의
```
z(disp15) <= -10.0   AND   z(oichg15) <= -2.5
disp15  = ln(C[t] / C[t-15])
oichg15 = ln(OI[t] / OI[t-15])
robust z = (x - median_30d) / (1.4826 * MAD_30d), 전날까지 30일
```

### 가설
15분 안에 10시그마 급락이 일어나고 **동시에 미결제약정이 줄어드는** 순간은 새 정보가 아니라
레버리지 포지션의 강제 청산일 확률이 높다. 강제 매도가 끝나면 가격이 되돌아온다.

## 2. C2 - E1 EXTREME_DELEVERAGING (SHORT)


기존 연구의 LONG 편향은 버킷 수준 평균회귀에서 나온 것이지 강제 청산 사건에서 검증된 적이 없다.

## 3. C3 - E3 VOLATILITY_SHOCK (LONG)

### 정의
```
z(disp15) <= -5.0   AND   volratio >= 4.0
volratio = rv15 / rv1440   (원값, z 미적용)
```

`HIGH volatility`는 **상태**이고 `volatility shock`은 **사건**이다. D6-C가 상태 조건을 반증했으므로
(G9: HIGH가 MID보다 나쁨) 이번에는 15분 변동성이 24시간 변동성의 4배로 팽창하면서 동시에
5시그마 급락한 **순간**만 사건으로 본다.

## 5. E2 - EXTREME_BASIS_DISLOCATION (계약 단계 탈락)

**백테스트하지 않았다.** cost-first 스크린(변위 ≥ 비용의 6배 = 67.5bp)을 어느 임계값에서도 통과하지 못했다.

| 임계값 | OOS 이벤트 | median 괴리 | 비용 배수 | 표본 하한 |
|---|---|---|---|---|
| LONG z ≤ -4 | 364 | 11.2bp | 1.00x | OK |
| LONG z ≤ -8 | 83 | 23.5bp | 2.08x | FAIL |
| LONG z ≤ -12 | 44 | 28.9bp | 2.57x | FAIL |
| **SHORT z ≥ +8** | 155 | **7.1bp** | **0.63x** | FAIL |
| SHORT z ≥ +12 | 48 | 17.8bp | 1.59x | FAIL |

**E2-SHORT는 괴리가 전량 정상화돼도 비용보다 작다.** 표본이 충분한 임계값은 비용 배수가 1 근처이고,
비용 배수가 2를 넘는 임계값은 연도당 2~7건뿐이다.

D5.2가 spot-perp·cross-exchange basis를 660셀 돌려 "방향은 맞지만 비용 이하"로 판정한 것과
같은 결론이며, 이번에는 **feature 크기만 보고 백테스트 전에** 얻었다.

# CRYPTO BTC-VOL-P0 DATA REQUIREMENTS V1

2026-09-28. **데이터 구매 0.** 출처·비용·커버리지만 정리한다. 구매 결정은 사용자 몫이다.

---

## 1. 무엇이 있어야 답이 나오는가

VOL-P0의 결론(`ECONOMICALLY_UNPROMISING`)은 **대리 지표**로 나왔다.
IV를 직접 재지 않고, IV의 주된 동인인 직전 실현변동성을 썼다.

확정하려면 딱 하나가 필요하다:

> **P1 고신뢰 신호 시점의 실제 ATM 내재변동성.**

손익분기는 이미 계산돼 있다: **4H 120.0%, 12H 86.5%, 24H 89.1%.**
그 시점의 실제 IV가 이 아래면 R1이 살아나고, 위면 확정 기각이다.

---

## 2. 최소 필요 필드

| 필드 | 필수 | 이유 |
|---|---|---|
| timestamp | 필수 | P1 결정시각과 join |
| underlying / index price | 필수 | 등가격 판정 |
| strike, expiry, type | 필수 | ATM 선택 |
| **mark_iv** | **필수** | 손익분기 비교의 대상 |
| bid, ask | 필수 | 실제 체결 가능 가격. mark만으로는 스프레드를 못 본다 |
| bid_iv, ask_iv | 강력 권장 | 매수 측 실효 IV |
| delta | 권장 | ATM 식별 보조 |
| gamma, vega, theta | 선택 | 조기 청산 시나리오 |
| open interest, volume | 선택 | 유동성 판단 |

**해상도**: P1 결정이 정시 1시간 간격이므로 **시간별이면 충분하다.**
분 단위는 불필요하다.

**기간**: P1 고신뢰 신호를 충분히 덮어야 한다. §4가 이것을 수치로 다룬다.

## 3. 무료 공식 데이터

### 3.1 Binance `data.binance.vision` - 필드는 완벽, 기간이 치명적

**직접 확인**(S3 버킷 조회 + 파일 다운로드).

```
data/option/daily/EOHSummary/BTCUSDT/
```

컬럼: `date, hour, symbol, underlying, type, strike, open, high, low, close,
volume_contracts, volume_usdt, best_bid_price, best_ask_price, best_bid_qty,
best_ask_qty, best_buy_iv, best_sell_iv, mark_price, mark_iv, delta, gamma,
vega, theta, openinterest`

**§2의 필수 항목을 전부 포함한다.** 시간별 해상도도 정확히 맞는다.

| 항목 | 값 |
|---|---|
| 파일 수 | **147** |
| 구간 | **2023-05-18 ~ 2023-10-23** |
| `IsTruncated` | false (더 없음) |
| 파일 크기 | 약 400 KB/일 (압축) |
| 전체 | 약 **59 MB** |

### 3.2 다른 곳

| 거래소 | 자체 과거 옵션 데이터 |
|---|---|
| Deribit | `history.deribit.com` REST로 체결 이력(간접 확인). **체결이지 체인 스냅샷이 아니다** - IV를 직접 주지 않음 |
| OKX | **없음**(공식 historical-data 페이지에 옵션 부재) |
| Bybit | 찾지 못함 |

**Deribit의 체결 이력은 IV 시계열이 아니다.** 체결에서 IV를 역산하려면
그 시점 underlying·무위험이자율·정확한 만기가 필요하고, 체결이 없는 시간대는 공백이다.

## 4. 147일로 무엇을 할 수 있나 (결정적 계산)

P1 예측을 Binance 데이터 구간으로 잘라 직접 세었다.

| 조합 | p>=0.60 | p>=0.70 | **p>=0.75** |
|---|---|---|---|
| 4H ±1% | 9 episodes | 1 | **1** |
| 12H ±1% | 64 episodes | 18 | **5** |
| 12H ±2% | 3 episodes | 1 | **1** |
| 24H ±2% | 13 episodes | 1 | **1** |

**고신뢰 신호가 1~5개다.**

2023년 5~10월은 BTC가 좁은 범위에서 움직인 저변동성 구간이라
P1 고신뢰 상태 자체가 거의 발생하지 않았다.

> **무료 데이터로는 §1의 질문에 답할 수 없다.**
> 1~5개 표본으로는 "IV가 120%보다 낮은가"를 판정할 수 없다.

유일하게 숫자가 있는 칸은 12H ±1% p>=0.60의 64 episodes인데,
그것은 훨씬 약한 게이트이고 손익분기도 다르다.

**그리고 2023년만 본다는 것 자체가 문제다** - 저변동성 한 해에서
"IV가 비쌌나"를 재면 그 답이 모든 regime에 적용되지 않는다.

### 5.1 얼마나 사야 하는가

P1 검증 구간은 2022-01 ~ 2026-09(4.72년)다. 그 전체를 덮으려면:

| 조합 | p>=0.75 신호 |
|---|---|
| 4H ±1% | 274 |
| 12H ±1% | 1,066 |
| 24H ±2% | 253 |

**4H 기준 274개 신호**면 "IV 중앙값이 120%보다 낮은가"를 충분히 판정할 수 있다.

Tardis의 Options 스코프가 필요하고, 전체 히스토리 접근이면 최소 **Solo 등급($700-1,200/월)**,
연구 기간을 1~2개월로 잡으면 **약 $700~2,400**이다.

**단 사기 전에 §7을 먼저 하는 것이 합리적이다.**

### 5.2 무료로 먼저 확인할 수 있는 것

**Tardis는 Deribit 데이터를 매월 1일 무료로 준다**(공식 파트너십, API 키 불필요).

2022-01 ~ 2026-09 = **57개월 = 57일치**가 무료다.
그 57일에 P1 고신뢰 신호가 몇 개 떨어지는지는 계산하면 바로 나온다.
분포가 균일하다면 4H 기준 **274 × 57/1724 ≈ 9개** 정도로, 여전히 부족하다.

**그래도 IV 수준 자체를 보는 데는 쓸 수 있다.**
"P1 고신뢰 상태의 IV가 대체로 어느 대역인가"를 9개 표본으로 보는 것은,
"120%보다 확실히 위인가 아래인가"를 가르는 데 충분할 수 있다.
IV가 150%대면 9개로도 결론이 나고, 115~125% 부근이면 더 필요하다.

**이것이 가장 비용 효율적인 다음 한 걸음이다.**

## 6. 전방 수집 가능성

무료로 과거를 못 사면 앞으로 모으는 길이 있다.

### 6.1 용량

BTC 옵션 체인 규모를 공식 API 기준으로 추정하면:

| 항목 | 값 |
|---|---|
| 활성 instrument 수 | 수백 (Binance 700+ 계약, 전 underlying 합산) |
| 행당 크기 | 약 200 바이트 |
| 시간별 수집 | 약 **2.4 MB/일** → **0.9 GB/년** |
| 5분 수집 | 약 29 MB/일 → **10.5 GB/년** |
| gzip 후 | 약 1/8 |

**시간별이면 gzip 후 연 100~150 MB.** 부담이 전혀 아니다.
P1 결정이 정시 1시간 간격이므로 **시간별로 충분하다.**

기술적 장벽도 없다. 네 거래소 모두 공개 API로 IV와 greeks를 준다.

### 6.2 그런데 시간이 오래 걸린다

| 조합 | 연간 p>=0.75 신호 | 274개(현 표본 수준) 모으는 데 |
|---|---|---|
| 4H ±1% | **27** | **10년** |
| 12H ±1% | 74 | 3.7년 |
| 24H ±2% | 28 | 9년 |

**전방 수집만으로 R1을 검증하려면 수년이 걸린다.**

다만 목표를 낮추면 다르다. "IV가 손익분기보다 위인가 아래인가"만 보는 데는
**30~50개 신호면 충분**할 수 있고, 그건 12H 기준 6개월, 4H 기준 1~2년이다.

### 6.3 이번 단계에서 배포하지 않는다

계약 §9. collector를 만들지도 배포하지도 않았다. **가능성만 평가했다.**

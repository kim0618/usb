## 38. Limitations

| # | 한계 |
|---|---|
| 1 | **R1 판정이 대리 지표 기반이다.** IV를 직접 재지 않았다. 다만 대리 지표가 가장 관대한 방향이므로 실제는 더 나쁠 것이다 |
| 2 | **모든 계산이 만기 보유 가정이다.** 조기 청산은 계산하지 않았고, 그것이 가장 유력한 반증 경로다(§35 B) |
| 3 | Deribit·Bybit·OKX 수수료·계약명세가 **간접 확인**이다(봇 차단·타임아웃·JS 렌더링). 단 전부 비용이라 판정을 바꾸지 않는다 |
| 4 | **Binance 옵션의 한국 접근성 UNKNOWN.** 사용자가 계정을 가진 곳인데 확인하지 못했다 |
| 5 | 호가 깊이·유동성 **미측정** |
| 6 | Brenner-Subrahmanyam 근사는 로그정규를 가정한다. BTC는 꼬리가 두껍다. 실측 평균 \|endpoint\|(2.046%)와 근사값(2.114%)의 차이가 그 영향이며, **차이가 판정을 바꾸는 크기는 아니다** |
| 7 | P1 신호가 연 27~74회로 드물어 어떤 검증도 표본이 느리게 쌓인다 |
| 8 | 2022~2026 한 구간만 봤다. 다른 변동성 체제에서 결론이 같다는 보장은 없다 |

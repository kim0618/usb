## 1. 공통 사건 원천 - SHOCK

```
|z(disp15)| >= 10.0   AND   z(oichg15) <= -2.5
```

**D5.4 E1 detector를 그대로 쓰되 양방향으로 합집합**했다. threshold 변경 0,
코드는 `app.crypto.research.d5_4.events` 재사용.

| 항목 | 값 |
|---|---|
| OOS 사건 | **415** |
| 연도별 | 2022: 94 / 2023: 157 / 2024: 53 / 2025: 58 / 2026: 53 |
| 방향 | 급등 199 / 급락 216 |
| shock window range | p25 165bp / median 218bp / p75 303bp |

**사건 원천을 하나로 고정한 이유**: 이번 연구의 변수는 확인 논리다. 후보마다 사건이 다르면
"확인이 도움이 되는가"와 "어느 사건이 나은가"가 섞인다.

## 2. A - SHOCK_BREAKOUT_CONTINUATION

### 정의
```
margin m = max(0.25 * R, 22.5bp)
UP   : close > H * (1 + m)  ->  LONG,  손절 = H
DOWN : close < L * (1 - m)  ->  SHORT, 손절 = L
목표 없음. 최대 보유 240 bar.
```

### 가설
충격이 만든 range를 의미 있는 폭으로 벗어난다는 것은 충격을 만든 흐름이 아직 끝나지 않았다는 신호다.

## 3. B - SHOCK_RETRACEMENT_CONFIRMATION

### 정의
```
급락: level = L + 0.5 * (P0 - L)   close > level -> LONG,  손절 = L, 목표 = P0
급등: level = H - 0.5 * (H - P0)   close < level -> SHORT, 손절 = H, 목표 = P0
최대 보유 240 bar. 진입 시 목표까지 남은 공간 < 22.5bp면 NO_TRADE.
```

### 가설
충격이 절반 되돌려졌다는 것은 강제 흐름이 끝나고 정상화가 실제로 진행 중이라는 뜻이다.
**D5.4는 충격 극값에서 바로 들어갔고, 여기서는 절반이 되돌아온 것을 보고 들어간다.**

확인은 **"맞는 방향에 서는 빈도"를 고쳤지만 "맞았을 때 얼마나 버는가"를 고치지 못했다.**

## 4. C - POST_SHOCK_COMPRESSION_EXPANSION

### 정의
```
1단계 압축: rv15[i] < 0.5 * rv15[event.start] 인 최초 bar
2단계 range: CH/CL = 그 bar까지 15 bar의 mark 고가/저가
3단계 확장: close > CH*(1+22.5bp) -> LONG / close < CL*(1-22.5bp) -> SHORT
손절 = 압축 range 반대편. 목표 없음. 최대 보유 240 bar.
```

### 가설
충격 → 소화 → 해소. 변동성이 절반으로 수축한 뒤의 돌파는 시장이 방향을 정했다는 신호다.

## 6. S10이 말해주는 것

계약은 S10(손절 비율 < 50%)을 "이번 연구의 핵심 게이트"로 지정했다. D5.4의 발견이
"사건 시점에 방향 정보가 없다"였으므로, 확인이 그것을 고쳤다면 손절이 절반 미만이어야 한다.

| 후보 | 손절 비율 | S10 |
|---|---|---|
| A | 71.3% | **FAIL** |
| B | 31.6% | **PASS** |
| C | 39.4% | **PASS** |

**2/3이 통과했다. 확인은 방향 정보를 만든다.** 그러나 그 정보가 비용을 넘는 크기의
수익으로 바뀌지 않았다.

이것이 D5.5가 D5.4에 더한 구체적인 지식이다: **문제는 "방향을 모른다"에서
"방향은 조금 아는데 그것으로 버는 금액이 수수료보다 작다"로 옮겨갔다.**

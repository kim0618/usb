작성 2026-09-28. 동결 계약 `CRYPTO_D6_AUTO_STRATEGY_DESIGN_CONTRACT_V1.md`의 13절 게이트를
**어떤 절차로 판정할지**를 정한다. 이 문서도 D6-C 실행 전에 동결한다.

## 1. 선택 편향 경고 (가장 먼저 읽을 것)

> **FDN-V1의 설계는 2021~2026 구간의 결과를 이미 본 상태에서 만들어졌다.**

| # | 사실 |
|---|---|
| B1 | D5(540셀)·D5.1(720셀)·D5.2(720셀)가 **같은 기간**을 이미 전수 탐색했다. 주요 셀만 1,980개 |
| B2 | FDN-V1의 네 성분은 그 탐색에서 살아남은(정확히는 **가장 덜 죽은**) 축들이다 |
| B3 | 후보의 핵심 구조(할인 ∩ OI감소 ∩ 변동성)는 D5.2 720셀 중 비용을 넘은 **유일한 1셀**에서 왔다. 귀무가설에서도 약 18셀이 우연히 통과할 규모의 탐색이었다 |
| B4 | 따라서 **2022-01-01 ~ 2026-09-23 구간의 어떤 부분도 untouched holdout이 아니다.** 이 문서에서 "holdout"이라는 단어를 쓰지 않는다 |
| B5 | D6-C가 PASS해도 그것은 **"기존 관측과 모순되지 않는다"**는 뜻이지 **"edge가 검증됐다"**가 아니다 |

**진짜 out-of-sample은 D6-D(realtime shadow) 이후에만 생긴다.** 그래서 승격 경로에 D6-D가 있다.

이 경고는 결과 문서 첫 장에 그대로 옮겨 적는다.

## 3. Walk-forward 설계 (동결)

**D5.1 계약 2절의 fold 표를 글자 그대로 재사용한다.** 새 fold 경계를 만들지 않는다.

| fold | train | test |
|---|---|---|
| F1 | 2021-03-04 ~ 2022-01-01 | 2022-01-01 ~ 2022-07-01 |
| F2 | ~ 2022-07-01 | 2022-07-01 ~ 2023-01-01 |
| F3 | ~ 2023-01-01 | 2023-01-01 ~ 2023-07-01 |
| F4 | ~ 2023-07-01 | 2023-07-01 ~ 2024-01-01 |
| F5 | ~ 2024-01-01 | 2024-01-01 ~ 2024-07-01 |
| F6 | ~ 2024-07-01 | 2024-07-01 ~ 2025-01-01 |
| F7 | ~ 2025-01-01 | 2025-01-01 ~ 2025-07-01 |
| F8 | ~ 2025-07-01 | 2025-07-01 ~ 2026-01-01 |
| F9 | ~ 2026-01-01 | 2026-01-01 ~ 2026-09-23 |

OOS = F1~F9 test 합 = **2022-01-01 ~ 2026-09-23**.

| # | 규칙 |
|---|---|
| W1 | **rolling calibration 없음.** FDN-V1에는 적합할 파라미터가 없다. bucket cutoff는 전부 과거 30일 rolling이라 이미 PIT이고, score weight·threshold·손절 k는 이 계약에 상수로 동결돼 있다 |
| W2 | 따라서 train 구간은 **판정에 쓰지 않는다.** D5.1의 "WF 선택"(train net 부호로 방향 선택)도 하지 않는다. 방향은 LONG 고정이기 때문이다 |
| W3 | train을 쓰지 않으므로 fold는 사실상 **시간 분할 보고 단위**다. 이 사실을 결과에 명시한다. fold를 "학습/검증"으로 부르지 않는다 |
| W4 | Embargo: 진입 bar부터 청산 bar까지가 fold 경계를 가로지르면 그 거래는 버린다 |

## 4. PIT 강제 (테스트로 증명)

| # | 규칙 | 검증 방법 |
|---|---|---|
| P1 | bar `t`의 결정은 `t` 이전에 마감된 bar만 본다 | 미래 bar를 변조해도 결정이 불변임을 테스트 |
| P2 | 진입은 `open[t+1]`, 같은 bar 진입 금지 | 단위 테스트 |
| P3 | OI는 기록 시각 + 5분에 가용 | 단위 테스트 |
| P4 | bucket cutoff는 `[D-30일, D)`만 사용 | D5 `bucketize` 재사용(코드 무수정) |
| P5 | 변동성 cutoff는 **D5.1이 F1 train에서 동결한 상수**. 전체 구간 분위수로 다시 계산하지 않는다 | 상수 대조 |
| P6 | funding은 정산 시각에 가용 | 단위 테스트 |
| P7 | 손절 판정은 bar 내부 순서를 가정하지 않는다. **같은 bar에서 손절가와 목표를 동시에 만족하면 손절을 택한다**(보수적) | 단위 테스트 |

P7은 중요하다. 1m bar의 high/low 순서를 모르므로 **불리한 쪽으로 해석**한다.

## 5. 실행 arm (동결)

| arm | 내용 | 판정 |
|---|---|---|
| **A-MAIN** | 계약 그대로: score ≥ 50, 4h, 손절 k=2.5, 1x, 위험예산 0.5% | **이 arm으로 판정한다** |
| A-NOSTOP | 손절 없음. 나머지 동일 | G11 sanity check 전용. **판정 불가** |
| A-SENS-1 | score threshold 37 | G8 |
| A-SENS-2 | score threshold 62 | G8 |
| A-SENS-3 | 손절 k = 2.0 | G8 |
| A-SENS-4 | 손절 k = 3.0 | G8 |
| A-SENS-5 | OI 창 30분 | G8 |
| A-SENS-6 | OI 창 120분 | G8 |
| A-REF-2h | 보유 2h | **보고 전용. 판정 금지** |
| A-REF-8h | 보유 8h | **보고 전용. 판정 금지** |

| # | 규칙 |
|---|---|
| E1 | arm은 **이 10개뿐이다.** D6-C에서 arm을 추가하지 않는다 |
| E2 | A-REF-2h / A-REF-8h가 A-MAIN보다 좋아도 **후보를 바꾸지 않는다.** best horizon cherry-picking 금지 |
| E3 | A-SENS는 **G8 통과 여부만** 본다. 가장 좋은 SENS를 새 기본값으로 삼지 않는다 |
| E4 | 전 arm 결과를 필터 없이 JSON으로 남긴다 |

## 6. 통계

| 항목 | 방법 |
|---|---|
| 관측 단위 | **거래 1건**(진입-청산). D5 계열의 "매 bar 표본"과 다르다. 쿨다운 60분으로 겹치지 않는다 |
| 수익률 정의 | 명목 대비 순손익(bp) = (체결 기준 손익 - 수수료 - funding) / 진입 명목 |
| CI | 거래 단위 **7 UTC일 moving block bootstrap 1,000회, seed 20260928** (D5.1·D5.2와 같은 방식·같은 블록 길이) |
| N_eff | 거래는 겹치지 않으므로 N_eff = 거래 수 |
| 자본 곡선 | 8절 sizing을 실제 적용한 복리 곡선. PF·MDD는 여기서 계산 |
| edge/cost ratio | `gross 평균 / (gross 평균 - net 평균)`, VIP0_BASE 기준 |
| p-value | **쓰지 않는다.** CI와 비용 대비 크기로만 판정 |

**다중검정 규모 기록**: 이번 D6-C의 판정 대상은 **arm 1개(A-MAIN) x 게이트 11개**다. 셀 탐색이 아니다.
그러나 **이 후보 자체가 앞선 1,980셀 탐색의 산물**이라는 점(1절)이 실질적인 다중검정이며, 그것은 CI로 교정할
수 없다. D6-D forward만이 교정한다.

## 8. 판정 절차

```
1. 계약 hash 검증 → 불일치면 중단
2. A-MAIN 실행 → G1~G7, G9, G10 판정
3. A-SENS 1~6 실행 → G8 판정
4. A-NOSTOP 실행 → G11 sanity
5. A-REF 2h/8h 실행 → 보고에만 기재
6. 게이트 전부 PASS → AUTO_CANDIDATE_PASS
   하나라도 FAIL → FAIL (이 계약 아래 재시도 금지)
```

| # | 규칙 |
|---|---|
| V1 | **게이트 숫자를 결과를 본 뒤 옮기지 않는다** |
| V2 | FAIL이면 "조건을 조금 바꿔 다시"를 하지 않는다. 새 사전등록(V2)이 필요하고, 그 결정은 사용자 몫이다 |
| V3 | PASS여도 AUTO를 시작하지 않는다. D6-D → D7 순서를 지킨다 |
| V4 | 결과 문서에 1절 선택 편향 경고를 그대로 옮긴다 |
